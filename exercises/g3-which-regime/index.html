The three rules

Compare the particle size to the wavelength of light. Blue is 400 nm, red is 700 nm: the two ends of what you can see.

Rayleigh — particle ≪ λ (a tenth or less). Scattering ∝ 1/λ⁴, so 400 nm scatters (700/400)⁴ ≈ 9× more than 700 nm → blue.
Mie — particle ≈ λ or a bit bigger. Every wavelength scatters about the same → white. Unless the scatterers sit at one repeated spacing — then one wavelength is reinforced (the jay).
Geometric — particle ≫ λ (ten times or more). Rays, mirrors, lenses; every wavelength alike → white.

Units first, always: 1 µm = 1,000 nm Put size and wavelength in the same unit before you divide.

2 · Worked example: the keratin air pocket (200 nm)

Every row below follows these seven steps. Here they are filled in for one particle.

a Size in nm
200 nm — already in nm, so nothing to convert. (If it had said 0.2 µm: 0.2 × 1,000 = 200 nm.)
b Size ÷ 400 nm (blue)
200 ÷ 400 = 0.50 — same unit top and bottom, so the ratio is a plain number with no unit.
c Size ÷ 700 nm (red)
200 ÷ 700 = 0.29 — the same pocket looks smaller to a longer wave.
d Compare the ratio to 1
≈ 1 (about half) — not a hundredth like a molecule, not ten times like a droplet: the same order of size as the wave.
e Regime
Rayleigh → Mie edge (~λ/2) — by size alone, only a weak preference for blue would be expected.
f Colour of the scattered light
blue (over melanin) — the pockets sit at one repeated spacing, so the returned waves add in step at one wavelength ≈ 2 × spacing × ~1.3. Coherent scattering: size gets you to the edge, spacing picks the colour.
g Natural example
blue-jay feather — ordered in distance, disordered in direction, so it is the same blue from every angle.
