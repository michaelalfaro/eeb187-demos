Instructor Walkthrough — Chaetodontidae

End-to-end recipe path on the butterflyfish exemplar set

Note

This site mirrors the student experience of receiving a FishView bundle and running it through the project recipe book. The clade is Chaetodontidae (butterflyfishes), the same dataset used for the published divergence analysis here.

It exists so the TA and you can inspect recipe fidelity, step ordering, and figure quality without spinning up a student account on FishView. No student group is assigned to Chaetodontidae — this is purely instructor-facing.

What’s in the bundle

The bundle/ directory matches the FishView “Export Bundle” layout that students get from their dashboard, plus two cached intermediates so the recipes render fast.

bundle/
├── images/
│   └── <Genus_species>.png      ← 130 exemplar PNGs
├── chaetodontidae-tree.tre      ← 109-tip chronogram (crown ~43 Ma)
├── picked_species.txt           ← exemplar list
├── picked_tip_labels.txt        ← tree tips matching exemplars
├── README.txt
├── pavo_classify.rds            ← cached pavo::classify (run once)
└── phylo_pca.rds                ← cached phytools::phyl.pca (run once)

How a student would use this

  1. Know Your Clade → read the Chaetodontidae profile for natural history context.
  2. Recipes → run at minimum the three MVP recipes:
    • Foundation Recipe: Color Gamut
    • R1: Phylogenetic Signal (not built into this walkthrough — students run on student site)
    • R3: Axis of Diversification (not built into this walkthrough — students run on student site)
  3. Plus 1-2 electives. This walkthrough shows Continuous ASR as an elective example.
  4. Workbench → upload qmd + bundle, render, and pull the rendered HTML + figures into a poster.

Why these two recipes are built into the walkthrough

The user asked specifically to see:

  1. A color gamut in RGB space built from the pavo::classify cluster centers (background excluded), and
  2. Ancestral state reconstruction of PhyloPC 1–3 on the pavo metrics, on the exemplar tree.

These touch the two ends of the project workflow — gamut sits at the “what colors are in the clade?” end, ASR sits at the “how have those colors evolved?” end.

How the cached intermediates work

The recipes show the canonical pavo call as a code chunk, then comment it out and load the cached .rds. To re-run from scratch (e.g., if you change the exemplar set), uncomment the live call and delete the matching .rds. This keeps recipe code visible without paying the ~15-minute classify cost on every knit.
