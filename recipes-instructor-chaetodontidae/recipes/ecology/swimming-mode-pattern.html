Swimming Mode and Pattern

Does caudal fin shape predict stripe orientation in butterflyfishes?

Tip

Ecology recipe. PGLS regression of pavo pattern metrics against FishBase caudal fin aspect ratio. The motion dazzle hypothesis predicts that faster-swimming species (higher caudal AR) display more directional stripe patterns. We test this with pavo’s pattern transition density (m) and pattern aspect ratio (A), as well as the phylogenetic PC axes.

Poster outputs. figures/swimming-mode-hero.pdf – a multi-panel scatter with PGLS regression lines.

What you’re computing

  1. Load caudal fin aspect ratio from chaet_master_traits.csv (sourced from rfishbase::morphometrics()).
  2. Merge with pavo metrics and phylogenetic PC scores.
  3. Fit PGLS models: m ~ AspectRatio, A ~ AspectRatio, PC1 ~ AspectRatio.
  4. Scatter plots with regression lines.

PGLS models

fit_pgls <- function(response, predictor, df, tree) {
  f <- as.formula(paste(response, "~", predictor))
  starts <- c(0.5, 0.9, 0.1, 0.99, 0.01)
  ctrl <- glsControl(opt = "optim", maxIter = 200, msMaxIter = 200)
  for (lam0 in starts) {
    m <- tryCatch(
      gls(f, data = df,
          correlation = corPagel(lam0, tree, form = ~species, fixed = FALSE),
          method = "ML", control = ctrl),
      error = function(e) NULL)
    if (!is.null(m)) return(m)
  }
  gls(f, data = df,
      correlation = corPagel(1, tree, form = ~species, fixed = TRUE),
      method = "ML", control = ctrl)
}

extract_lambda <- function(m) {
  tryCatch(
    as.numeric(coef(m$modelStruct$corStruct, unconstrained = FALSE)),
    error = function(e) 1.0)
}

m_m   <- fit_pgls("m", "aspect_ratio", df, tree_sw)
m_A   <- fit_pgls("A", "aspect_ratio", df, tree_sw)
m_pc1 <- fit_pgls("PC1", "aspect_ratio", df, tree_sw)

lam_m   <- extract_lambda(m_m)
lam_A   <- extract_lambda(m_A)
lam_pc1 <- extract_lambda(m_pc1)

Summary table

make_row <- function(resp, m, lam, pred = "aspect_ratio") {
  tt <- summary(m)$tTable
  data.frame(
    Response = resp,
    Slope    = round(tt[pred, "Value"], 4),
    SE       = round(tt[pred, "Std.Error"], 4),
    t        = round(tt[pred, "t-value"], 2),
    p        = signif(tt[pred, "p-value"], 3),
    Lambda   = round(lam, 3),
    check.names = FALSE
  )
}

tab <- rbind(
  make_row("m (transition density)", m_m, lam_m),

Interpretation

Chaetodontidae are labriform swimmers with moderately low caudal fin aspect ratios (most between 1.5 and 3.8). The motion dazzle hypothesis predicts a positive relationship between caudal AR and pattern directionality (A), because faster-swimming species benefit more from stripes that create optical illusions during escape. Within butterflyfishes, the relationship may be weak because the family is ecologically constrained to reef-associated swimming modes. A significant slope on m or PC1 would suggest that caudal shape is also linked to overall pattern complexity, not just stripe orientation.
