Phylomorphospace — PC1 × PC2

Color-pattern morphospace with phylogeny overlaid and fish images as points

Tip

Elective recipe. Takes the cached phyl.pca from the bundle and projects all species into PC1 × PC2, then connects them through their reconstructed internal nodes (the classic Sidlauskas / phytools “phylomorphospace”). Each tip is plotted as the species’ exemplar image rather than a dot, so the morphospace itself shows the patterns the PCs are measuring.

Poster output. figures/phylomorphospace-PC1-PC2-hero.pdf — 12” × 9”, drops directly into Panel B of the 48”×36” template.

What you’re computing

  1. Load the cached phylogenetic PCA (phylo_pca.rds) — same object the continuous-asr recipe uses, so PC scores are comparable across the two recipes.
  2. Pull S (n species × n PCs) and keep columns 1 and 2.
  3. Estimate internal-node positions in PC1×PC2 with phytools::fastAnc (one ancestral-state reconstruction per axis under Brownian motion).
  4. Plot each tip as its exemplar PNG (head-left, auto-sized by tree size) and draw the phylogenetic edges connecting tips through internal nodes.
  5. Annotate the corner with variance explained and the top pavo-metric loadings per axis (no big table on the figure — that goes in the methods sidebar of the poster).

# Helper: read PNG and make magenta background transparent
read_fish_png <- function(path) {
  img <- readPNG(path)
  if (length(dim(img)) == 3) {
    if (dim(img)[3] == 3) {
      img <- array(c(img, rep(1, prod(dim(img)[1:2]))),
                   dim = c(dim(img)[1:2], 4))
    }
    mag <- img[,,1] > 0.8 & img[,,2] < 0.3 & img[,,3] > 0.8
    img[,,4][mag] <- 0
  }
  img
}

top_loaders <- function(v, k = 3) {
  ord <- order(abs(v), decreasing = TRUE)[seq_len(k)]
  paste0(names(v)[ord],
         sprintf("(%+.2f)", v[ord]),
         collapse = ", ")
}
pc1_top <- top_loaders(loadings[, 1])

Reconstruct internal-node positions

# Brownian ASR for each axis using fastAnc (same generative model as
# phyl.pca, so this is the consistent way to project ancestors).
anc1 <- fastAnc(tree, PC1)
anc2 <- fastAnc(tree, PC2)

# Combine tip + node coords into a single (n_tips + n_nodes) × 2 matrix,
# indexed by phylo's node numbering (tips 1..ntip, internals ntip+1..ntip+nnode).
n_tips <- length(tree$tip.label)
coords <- matrix(NA_real_, nrow = n_tips + tree$Nnode, ncol = 2,
                 dimnames = list(NULL, c("PC1", "PC2")))
coords[1:n_tips, 1] <- PC1[tree$tip.label]
coords[1:n_tips, 2] <- PC2[tree$tip.label]
coords[(n_tips + 1):nrow(coords), 1] <- anc1[as.character((n_tips + 1):(n_tips + tree$Nnode))]
coords[(n_tips + 1):nrow(coords), 2] <- anc2[as.character((n_tips + 1):(n_tips + tree$Nnode))]
stopifnot(!anyNA(coords))

Auto-size the tip images

The image width scales as sqrt(60 / n_tips) so a small tree gets large icons and a big tree gets small icons; clamped to a sane range. With 109 tips the formula gives roughly 0.44” per image on a 12”-wide canvas, which prints as a recognizable thumbnail at 48”-poster scale.

n_species <- length(tree$tip.label)

# image_width_in is the on-PDF image width in INCHES; we convert to PC1-axis
# units below using the data range.
image_width_in <- max(0.25, min(1.2, 0.6 * sqrt(60 / n_species)))
cat(sprintf("n_species = %d  →  image_width_in = %.3f in\n",
            n_species, image_width_in))
n_species = 109  →  image_width_in = 0.445 in

Plot helper

Code 
plot_pms <- function(out_pdf, w = 12, h = 9,
                     image_width_in = 0.44,
                     edge_col = "grey55", edge_lwd = 0.6,
                     bg_col = "white", border_col = "grey15",
                     point_fallback_col = "#1f77b4") {

  # Data ranges with a 12% pad so images near the edge don't get clipped.
  pad <- 0.12
  xr <- range(coords[, 1]); xr <- xr + diff(xr) * c(-pad, pad)
  yr <- range(coords[, 2]); yr <- yr + diff(yr) * c(-pad, pad)

  # Convert image width in inches to data units (PC1).
  # plot area width ≈ canvas width minus margins. Use a 70% effective ratio,
  # i.e., reserve 30% for margins.
  data_per_inch_x <- diff(xr) / (w * 0.70)
  data_per_inch_y <- diff(yr) / (h * 0.70)
  img_w_data <- image_width_in * data_per_inch_x
  img_h_data <- image_width_in * data_per_inch_y * 0.65  # fish are wider than tall

  pdf(out_pdf, width = w, height = h)
  par(bg = bg_col, mar = c(4.4, 4.4, 3.0, 1.2))
  plot(NA, NA, xlim = xr, ylim = yr,
       xlab = sprintf("PhyloPC1  (%.1f%% var)", ve[1]),
       ylab = sprintf("PhyloPC2  (%.1f%% var)", ve[2]),
       cex.lab = 1.2, cex.axis = 1.0, las = 1,
       main = "Chaetodontidae phylomorphospace · PC1 × PC2",
       font.main = 2, cex.main = 1.25)
  grid(col = "grey90", lty = "dotted")

  # Phylo edges first, so images paint over them.
  for (e in seq_len(nrow(tree$edge))) {
    p <- tree$edge[e, 1]; c <- tree$edge[e, 2]
    segments(coords[p, 1], coords[p, 2],
             coords[c, 1], coords[c, 2],
             col = edge_col, lwd = edge_lwd)
  }
  # Internal nodes as small filled circles for visual continuity.
  internal <- (n_tips + 1):nrow(coords)
  points(coords[internal, 1], coords[internal, 2],
         pch = 21, bg = "grey85", col = "grey45", cex = 0.55, lwd = 0.4)

  # Tip images
  for (i in seq_len(n_tips)) {
    sp <- tree$tip.label[i]
    png_path <- file.path(IMG_DIR, paste0(sp, ".png"))
    x <- coords[i, 1]; y <- coords[i, 2]
    if (file.exists(png_path)) {
      img <- read_fish_png(png_path)
      rasterImage(img,
                  xleft   = x - img_w_data / 2,
                  xright  = x + img_w_data / 2,
                  ybottom = y - img_h_data / 2,
                  ytop    = y + img_h_data / 2)
    } else {
      points(x, y, pch = 21, bg = point_fallback_col,
             col = border_col, cex = 1.4)
    }
  }

  # Corner annotation — small, NO big table.
  ann <- c(sprintf("PC1: %.1f%% var | top loaders: %s", ve[1], pc1_top),
           sprintf("PC2: %.1f%% var | top loaders: %s", ve[2], pc2_top),
           sprintf("n = %d species; internal nodes via fastAnc (BM)", n_species))
  legend("topright", legend = ann, bty = "n",
         cex = 0.72, text.col = "grey25")

  dev.off()
  invisible(out_pdf)
}

Reading the plot

  • Tips that sit far from the centroid have extreme color-pattern signatures on whatever the leading axes are (here: pattern density and color diversity).
  • Long thin edges = lineages that have moved a lot in morphospace per Ma; short edges connecting nearby points = stasis.
  • Crossing edges are typical and expected — phylomorphospace projects a high-dimensional Brownian process onto 2 axes, so apparent crossings in PC1×PC2 don’t violate phylogenetic constraints.
  • Cluster regions of similar-looking fish images = convergence on the leading pattern axes.

How to extend

  • Switch axes: pass S[, c(2, 3)] instead of S[, 1:2] to view PC2 × PC3. The same plot_pms() helper works.
  • Color edges by clade: assign each edge a color based on the genus of its descendant tip (cheap heuristic since most edges sit within one genus in a 109-tip family tree).
  • Layer environmental data: shade the background of the plot by the Brownian-reconstructed value of a co-evolving trait (e.g., depth).
