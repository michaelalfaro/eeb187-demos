Phylogeny with Traits — the Poster Hero Panel

Ladderized tree, staggered fish images, PC1 ASR branches, geologic time axis

Tip

The visual hero of the poster. This recipe builds the centerpiece of Panel C (28” × 24” on the 48” × 36” layout): a ladderized chronogram with

  • branches colored by PhyloPC1 ancestral state,
  • staggered fish images in two columns (odd/even tips) so every species gets an image without vertical overlap,
  • abbreviated species names (italic, “Chae. auri” format),
  • two trait-circle columns: PC1 (diverging palette) and trophic level (warm sequential palette),
  • a geologic time axis with epoch rectangles (Eocene–Pleistocene).

Poster output. figures/phylogeny-with-traits-hero.pdf (28” × 24”). One self-contained PDF, no external legend assembly needed.

What you’re computing

  1. Load the cached phylo_pca.rds for PC1–PC3 tip scores + the tree.
  2. Load bundle/chaet_traits.csv for trophic level (built by recipes/advanced/fetch_traits.R).
  3. Run phytools::contMap on PC1 over the ladderized tree.
  4. Plot with base graphics: tree on the left ~35 % of canvas, then five right-side columns:
    • Column A (odd tips): fish image
    • Column B (even tips): fish image
    • Column 3: abbreviated species name (italic)
    • Column 4: PC1 circle (diverging palette)
    • Column 5: trophic level circle (warm sequential palette)
  5. All tips get a fish image; odd-numbered tips sit in column A, even in column B, so there is no vertical crowding.
  6. Image aspect ratio is read from the PNG and preserved (fish are wider than tall, ~2:1).
  7. A geologic time axis with epoch rectangles sits below the tree.

read_fish_png <- function(path) {
  img <- readPNG(path)
  if (length(dim(img)) == 3) {
    if (dim(img)[3] == 3) {
      img <- array(c(img, rep(1, prod(dim(img)[1:2]))),
                   dim = c(dim(img)[1:2], 4))
    }
    mag <- img[,,1] > 0.7 & img[,,2] < 0.4 & img[,,3] > 0.7
    img[,,4][mag] <- 0
  }
  img
}

Color & size scales for the trait columns

# Diverging palette for PCs (signed values); sequential for the positive
# continuous traits.
div_pal <- colorRampPalette(c("#2c7bb6", "#abd9e9", "#ffffbf",
                              "#fdae61", "#d7191c"))(100)
seq_pal <- colorRampPalette(c("#f7fbff", "#c6dbef", "#6baed6",
                              "#2171b5", "#08306b"))(100)
warm_pal <- colorRampPalette(c("#fff5eb", "#fdd0a2", "#fd8d3c",
                               "#d94801", "#7f2704"))(100)

# Returns (col, cex) for a value within [vmin, vmax] under a given palette.
encode <- function(v, vmin, vmax, pal, min_cex = 0.45, max_cex = 1.45) {
  if (is.na(v)) return(list(col = "grey90", cex = min_cex, na = TRUE))
  v_clip <- pmin(pmax(v, vmin), vmax)
  idx    <- pmax(1, ceiling(100 * (v_clip - vmin) / (vmax - vmin)))
  cx     <- min_cex + (max_cex - min_cex) * (v_clip - vmin) / (vmax - vmin)
  list(col = pal[idx], cex = cx, na = FALSE)
}

# Pre-compute axis ranges so circles are comparable across the column.
rng_PC1  <- range(PC1, na.rm = TRUE)
rng_PC2  <- range(PC2, na.rm = TRUE)
rng_PC3  <- range(PC3, na.rm = TRUE)
# Symmetrize PC ranges around 0 so the diverging palette midpoint = 0.
sym <- function(r) { m <- max(abs(r)); c(-m, m) }
rng_PC1 <- sym(rng_PC1); rng_PC2 <- sym(rng_PC2); rng_PC3 <- sym(rng_PC3)

rng_tro  <- range(traits$trophic_level, na.rm = TRUE)
rng_bod  <- range(traits$body_size_cm,  na.rm = TRUE)

Plot helper

Code 
# Shortened species label: "Chae. auri" for Chaetodon_auriga
short_label <- function(sp) {
  parts <- strsplit(gsub("_", " ", sp), " ")[[1]]
  if (length(parts) < 2) return(sp)
  paste0(substr(parts[1], 1, 4), ". ", substr(parts[2], 1, 4))
}

# Geologic epochs relevant to a ~43 Ma butterfly-fish tree (ages in Ma)
EPOCHS <- data.frame(
  name  = c("Eocene", "Oligocene", "Miocene", "Pliocene", "Pleist."),
  start = c(56.0,      33.9,        23.03,     5.33,       2.58),
  end   = c(33.9,      23.03,       5.33,      2.58,       0.012),
  col   = c("#f5f0cc",  "#d6eacc",  "#c5dde8", "#e2d4e8",  "#f0e0d0"),
  stringsAsFactors = FALSE
)

plot_phylogeny_with_traits <- function(out_pdf,
                                       w = 28, h = 24,
                                       img_col_w_in = 3.0,
                                       name_col_w_in = 2.0,
                                       data_col_w_in = 1.0,
                                       legend_strip_h = 0.045) {

  n_tips  <- length(tree$tip.label)
  total_h <- max(nodeHeights(tree))

  # --- PDF device ----------------------------------------------------------
  pdf(out_pdf, width = w, height = h)
  on.exit(dev.off(), add = TRUE)

  # Right margin (inches) = 2 image cols + name col + 2 data cols + padding
  right_margin_in <- 2 * img_col_w_in + name_col_w_in +
                     2 * data_col_w_in + 1.0
  par(bg = "white", mar = c(6.0, 0.6, 3.2, right_margin_in), xpd = NA)

  # Tree occupies ~35 % of canvas via xlim
  tree_xlim <- c(0, total_h * 1.05)

  plot(cm1,
       fsize   = 0, ftype = "off",
       lwd     = 1.5,
       outline = FALSE,
       legend  = total_h * 0.35,
       leg.txt = "PhyloPC1 (pattern density)",
       xlim    = tree_xlim)
  title("Chaetodontidae · phylogeny + color-pattern axes + ecology",
        line = 1.4, cex.main = 1.6, adj = 0)

  # --- Coordinate bookkeeping ---------------------------------------------
  lpp   <- get("last_plot.phylo", envir = .PlotPhyloEnv)
  tip_x <- lpp$xx[seq_len(n_tips)]
  tip_y <- lpp$yy[seq_len(n_tips)]
  dy    <- if (n_tips > 1) (max(tip_y) - min(tip_y)) / (n_tips - 1) else 1

  # Data units per inch (horizontal)
  panel_in_w  <- w - par("mai")[2] - par("mai")[4]
  data_per_in <- diff(tree_xlim) / panel_in_w

  # --- Geologic time axis -------------------------------------------------
  # Time runs right-to-left: x = total_h - age
  epoch_band_y_bot <- min(tip_y) - dy * 2.5
  epoch_band_y_top <- min(tip_y) - dy * 0.5
  for (e in seq_len(nrow(EPOCHS))) {
    ep <- EPOCHS[e, ]
    x0 <- total_h - min(ep$start, total_h)
    x1 <- total_h - max(ep$end, 0)
    # Only draw if the epoch overlaps the tree span
    if (x1 < 0 || x0 > total_h) next
    x0 <- max(x0, 0); x1 <- min(x1, total_h)
    rect(x0, epoch_band_y_bot, x1, epoch_band_y_top,
         col = ep$col, border = NA)
    rect(x0, epoch_band_y_bot, x1, epoch_band_y_top,
         col = NA, border = "grey70", lwd = 0.4)
    text((x0 + x1) / 2, (epoch_band_y_bot + epoch_band_y_top) / 2,
         ep$name, cex = 0.75, col = "grey30", font = 2)
  }
  # Numeric time ticks
  tick_ages <- seq(0, floor(total_h / 5) * 5, by = 5)
  tick_x    <- total_h - tick_ages
  tick_y    <- epoch_band_y_bot
  segments(tick_x, tick_y, tick_x, tick_y - dy * 0.3, col = "grey50", lwd = 0.6)
  text(tick_x, tick_y - dy * 0.5,
       paste0(tick_ages, " Ma"), cex = 0.65, col = "grey40", adj = c(0.5, 1))

  # --- Column x-anchors (data-unit positions) ------------------------------
  x_right_edge <- max(tip_x) + total_h * 0.012   # gap after tree tips
  col_A_left   <- x_right_edge
  col_B_left   <- col_A_left + img_col_w_in * data_per_in
  col_name_ctr <- col_B_left + img_col_w_in * data_per_in +
                  (name_col_w_in / 2) * data_per_in
  col_pc_ctr   <- col_B_left + img_col_w_in * data_per_in +
                  name_col_w_in * data_per_in +
                  (data_col_w_in / 2) * data_per_in
  col_tr_ctr   <- col_pc_ctr + data_col_w_in * data_per_in

  img_w_A <- img_col_w_in * data_per_in * 0.92   # slight inner padding

  # --- Header labels -------------------------------------------------------
  header_y <- max(tip_y) + dy * 1.8
  text(col_A_left + img_w_A / 2, header_y, "Image (odd)",
       adj = c(0.5, 0.5), cex = 0.85, font = 2, col = "grey30")
  text(col_B_left + img_w_A / 2, header_y, "Image (even)",
       adj = c(0.5, 0.5), cex = 0.85, font = 2, col = "grey30")
  text(col_name_ctr, header_y, "Species",
       adj = c(0.5, 0.5), cex = 0.85, font = 2, col = "grey30")
  text(col_pc_ctr, header_y, "PC1",
       adj = c(0.5, 0.5), cex = 1.0, font = 2, col = "grey20")
  text(col_tr_ctr, header_y, "Trophic",
       adj = c(0.5, 0.5), cex = 1.0, font = 2, col = "grey20")

  # --- Per-tip rendering ---------------------------------------------------
  for (i in seq_len(n_tips)) {
    sp   <- tree$tip.label[i]
    y_c  <- tip_y[i]
    is_odd <- (i %% 2 == 1)

    # Determine which image column this tip uses
    img_x_left <- if (is_odd) col_A_left else col_B_left

    # Fish image (aspect-ratio-preserving) --------------------------------
    png_path <- file.path(IMG_DIR, paste0(sp, ".png"))
    if (file.exists(png_path)) {
      img <- read_fish_png(png_path)
      img_aspect <- dim(img)[2] / dim(img)[1]   # width / height
      img_w_data <- img_w_A
      img_h_data <- img_w_data / img_aspect
      # Clamp if taller than row spacing
      max_h <- dy * 0.92
      if (img_h_data > max_h) {
        img_h_data <- max_h
        img_w_data <- img_h_data * img_aspect
      }
      rasterImage(img,
                  xleft   = img_x_left,
                  xright  = img_x_left + img_w_data,
                  ybottom = y_c - img_h_data / 2,
                  ytop    = y_c + img_h_data / 2,
                  interpolate = TRUE)
    }

    # Abbreviated species name --------------------------------------------
    text(col_name_ctr, y_c, short_label(sp),
         adj = c(0.5, 0.5), cex = 0.60, font = 3, col = "grey15")

    # PC1 circle -----------------------------------------------------------
    enc_pc <- encode(PC1[sp], rng_PC1[1], rng_PC1[2], div_pal)
    points(col_pc_ctr, y_c, pch = 21,
           bg  = enc_pc$col,
           col = if (enc_pc$na) "grey60" else "grey25",
           cex = enc_pc$cex * 1.6, lwd = 0.4)

    # Trophic level circle -------------------------------------------------
    tro_val <- traits$trophic_level[traits$species == sp]
    if (length(tro_val) == 0) tro_val <- NA
    enc_tr <- encode(tro_val, rng_tro[1], rng_tro[2], warm_pal)
    points(col_tr_ctr, y_c, pch = 21,
           bg  = enc_tr$col,
           col = if (enc_tr$na) "grey60" else "grey25",
           cex = enc_tr$cex * 1.6, lwd = 0.4)
  }

  # --- Per-column legend strips (bottom right) ----------------------------
  legend_y <- min(tip_y) - dy * 5.5
  for (info in list(
    list(xc = col_pc_ctr, rng = rng_PC1, pal = div_pal,  lab = "PC1"),
    list(xc = col_tr_ctr, rng = rng_tro,  pal = warm_pal, lab = "Trophic")
  )) {
    xc  <- info$xc; rng <- info$rng; pal <- info$pal
    n_steps <- 5
    sw <- data_col_w_in * data_per_in * 0.4
    sh <- dy * 0.35
    for (k in seq_len(n_steps)) {
      val <- rng[1] + (k - 0.5) / n_steps * (rng[2] - rng[1])
      idx <- pmax(1, ceiling(100 * (val - rng[1]) / (rng[2] - rng[1])))
      rect(xc - sw / 2,
           legend_y - sh * (n_steps - k),
           xc + sw / 2,
           legend_y - sh * (n_steps - k - 1),
           col = pal[idx], border = "grey40", lwd = 0.3)
    }
    text(xc, legend_y + sh * 0.4,
         sprintf("%.2g", rng[2]), adj = c(0.5, 0), cex = 0.70, col = "grey25")
    text(xc, legend_y - sh * n_steps - sh * 0.3,
         sprintf("%.2g", rng[1]), adj = c(0.5, 1), cex = 0.70, col = "grey25")
  }

  # --- Provenance note -----------------------------------------------------
  mtext(sprintf(
    "n = %d species  |  PC scores: phyl.pca (BM, corr)  |  trophic: rfishbase v%s  |  epochs approximate",
    n_tips, packageVersion("rfishbase")),
    side = 1, line = 4.5, cex = 0.65, col = "grey35", adj = 0)

  invisible(out_pdf)
}

Tunable parameters

Parameter Default Effect
img_col_w_in 3.0 Width (inches) allocated to each image column; increase for fewer tips
name_col_w_in 2.0 Width for the abbreviated species-name column
data_col_w_in 1.0 Width for each data-circle column (PC1, Trophic)
w, h 28, 24 Match to the poster panel; for an 11 x 17 handout try w=11, h=17

How to swap traits

The two trait columns are defined inside the for (info in list(...)) loop near the end of plot_phylogeny_with_traits(). Each entry is a named list with xc, rng, pal, and lab. To replace “Trophic” with, say, “Body size (cm)”, change rng_tro to rng_bod, warm_pal to seq_pal, and update the lookup inside the per-tip loop.
