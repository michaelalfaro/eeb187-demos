Phylogeny with Traits — the Poster Hero Panel

Ladderized tree, PC1 ASR on branches, exemplar images at tips, trait circles to the right

Tip

The visual hero of the poster. This recipe builds the centerpiece of Panel C (28” × 24” on the 48” × 36” layout): a ladderized chronogram with

  • branches colored by PhyloPC1 ancestral state,
  • tips = exemplar fish images + species names (every other by default),
  • five trait columns to the right of the tree: PC1, PC2, PC3, trophic level, body size (cm), each rendered as a filled circle whose color encodes the value.

Poster output. figures/phylogeny-with-traits-hero.pdf (28” × 24”). One self-contained PDF, no external legend assembly needed.

What you’re computing

  1. Load the cached phylo_pca.rds for PC1–PC3 tip scores + the tree.
  2. Load bundle/chaet_traits.csv for body size + trophic level (built by recipes/advanced/fetch_traits.R).
  3. Run phytools::contMap on PC1 over the ladderized tree.
  4. Plot with base graphics: tree on the left ~55% of canvas, then five circle-strip columns on the right.
  5. Tip rendering: image + species name (every other tip shows an image; the rest show name only — controlled by show_every_n, default 2).
  6. Image height auto-scales with n_tips so small trees get bigger icons. Formula: image_width_in = clamp(0.6 * sqrt(60 / n_tips), 0.25, 1.2).

read_fish_png <- function(path) {
  img <- readPNG(path)
  if (length(dim(img)) == 3) {
    if (dim(img)[3] == 3) {
      img <- array(c(img, rep(1, prod(dim(img)[1:2]))),
                   dim = c(dim(img)[1:2], 4))
    }
    mag <- img[,,1] > 0.8 & img[,,2] < 0.3 & img[,,3] > 0.8
    img[,,4][mag] <- 0
  }
  img
}

Color & size scales for the trait columns

# Diverging palette for PCs (signed values); sequential for the positive
# continuous traits.
div_pal <- colorRampPalette(c("#2c7bb6", "#abd9e9", "#ffffbf",
                              "#fdae61", "#d7191c"))(100)
seq_pal <- colorRampPalette(c("#f7fbff", "#c6dbef", "#6baed6",
                              "#2171b5", "#08306b"))(100)
warm_pal <- colorRampPalette(c("#fff5eb", "#fdd0a2", "#fd8d3c",
                               "#d94801", "#7f2704"))(100)

# Returns (col, cex) for a value within [vmin, vmax] under a given palette.
encode <- function(v, vmin, vmax, pal, min_cex = 0.45, max_cex = 1.45) {
  if (is.na(v)) return(list(col = "grey90", cex = min_cex, na = TRUE))
  v_clip <- pmin(pmax(v, vmin), vmax)
  idx    <- pmax(1, ceiling(100 * (v_clip - vmin) / (vmax - vmin)))
  cx     <- min_cex + (max_cex - min_cex) * (v_clip - vmin) / (vmax - vmin)
  list(col = pal[idx], cex = cx, na = FALSE)
}

# Pre-compute axis ranges so circles are comparable across the column.
rng_PC1  <- range(PC1, na.rm = TRUE)
rng_PC2  <- range(PC2, na.rm = TRUE)
rng_PC3  <- range(PC3, na.rm = TRUE)
# Symmetrize PC ranges around 0 so the diverging palette midpoint = 0.
sym <- function(r) { m <- max(abs(r)); c(-m, m) }
rng_PC1 <- sym(rng_PC1); rng_PC2 <- sym(rng_PC2); rng_PC3 <- sym(rng_PC3)

rng_tro  <- range(traits$trophic_level, na.rm = TRUE)
rng_bod  <- range(traits$body_size_cm,  na.rm = TRUE)

Plot helper

Code 
plot_phylogeny_with_traits <- function(out_pdf,
                                       w = 28, h = 24,
                                       show_every_n = 2,
                                       legend_strip_h = 0.045) {

  n_tips <- length(tree$tip.label)
  total_h <- max(nodeHeights(tree))

  # Auto-image size (inches → data units after the plot is set up).
  image_width_in <- max(0.25, min(1.2, 0.6 * sqrt(60 / n_tips)))

  pdf(out_pdf, width = w, height = h)

  # Reserve right margin for the 5 trait columns + bottom strip for legends.
  # Note: contMap's plot() draws its own scalebar in the bottom-left if
  # legend != FALSE; we pass legend = total_h * 0.4 to keep it inside.
  par(bg = "white", mar = c(4.0, 0.4, 3.2, 22.0))
  plot(cm1,
       fsize   = 0, ftype = "off",
       lwd     = 1.5,
       outline = FALSE,
       legend  = total_h * 0.45,
       leg.txt = "PhyloPC1 (pattern density)",
       xlim    = c(0, total_h * 1.05))
  title("Chaetodontidae · phylogeny + color-pattern axes + ecology",
        line = 1.4, cex.main = 1.6, adj = 0)

  lpp   <- get("last_plot.phylo", envir = .PlotPhyloEnv)
  tip_x <- lpp$xx[seq_len(n_tips)]
  tip_y <- lpp$yy[seq_len(n_tips)]

  # Per-row vertical spacing in data units.
  dy <- if (n_tips > 1) (max(tip_y) - min(tip_y)) / (n_tips - 1) else 1

  # Convert image width from inches to data units (rough — uses panel width).
  panel_in_w  <- w - sum(par("mai")[c(2, 4)])     # plot inches width
  data_per_in <- total_h * 1.05 / panel_in_w
  img_w_data  <- image_width_in * data_per_in
  img_h_data  <- dy * 0.85

  # x-anchor for tip glyphs
  x_glyph <- max(tip_x) + total_h * 0.012

  # Render tip rows
  for (i in seq_len(n_tips)) {
    sp  <- tree$tip.label[i]
    y_c <- tip_y[i]
    show_image <- ((i - 1) %% show_every_n == 0)
    png_path <- file.path(IMG_DIR, paste0(sp, ".png"))
    if (show_image && file.exists(png_path)) {
      img <- read_fish_png(png_path)
      rasterImage(img,
                  xleft   = x_glyph,
                  xright  = x_glyph + img_w_data,
                  ybottom = y_c - img_h_data / 2,
                  ytop    = y_c + img_h_data / 2)
      text(x_glyph + img_w_data / 2, y_c - img_h_data / 2 - dy * 0.18,
           gsub("_", " ", sp),
           adj = c(0.5, 1.0), cex = 0.55, font = 3, col = "grey15")
    } else {
      text(x_glyph, y_c, gsub("_", " ", sp),
           adj = c(0, 0.5), cex = 0.55, font = 3, col = "grey15")
    }
  }

  # ------ Trait circle columns -----------------------------------------
  # Lay out columns to the RIGHT of the image strip, in inches → data units.
  col_start_in <- image_width_in + 0.20   # gap after image
  col_w_in     <- 0.55                    # per-column width
  col_gap_in   <- 0.08
  col_total_in <- col_w_in + col_gap_in
  col_x_data   <- function(j) {
    x_glyph + img_w_data + (col_start_in + (j - 0.5) * col_total_in) * data_per_in
  }
  col_labels  <- c("PC1", "PC2", "PC3", "Trophic", "Body (cm)")
  col_pals    <- list(div_pal, div_pal, div_pal, warm_pal, seq_pal)
  col_ranges  <- list(rng_PC1, rng_PC2, rng_PC3, rng_tro, rng_bod)
  col_values  <- list(
    PC1[tree$tip.label],
    PC2[tree$tip.label],
    PC3[tree$tip.label],
    traits$trophic_level,
    traits$body_size_cm
  )

  # Header row for the columns
  header_y <- max(tip_y) + dy * 1.8
  for (j in seq_along(col_labels)) {
    text(col_x_data(j), header_y, col_labels[j],
         adj = c(0.5, 0.5), cex = 1.0, font = 2, col = "grey20")
  }

  # Circle rows
  for (j in seq_along(col_labels)) {
    v_all  <- col_values[[j]]
    rng    <- col_ranges[[j]]
    pal    <- col_pals[[j]]
    xc     <- col_x_data(j)
    for (i in seq_len(n_tips)) {
      enc <- encode(v_all[i], rng[1], rng[2], pal)
      points(xc, tip_y[i], pch = 21,
             bg = enc$col,
             col = if (enc$na) "grey60" else "grey25",
             cex = enc$cex * 1.6, lwd = 0.4)
    }
  }

  # Per-column compact legend strip across the bottom-right margin
  legend_y <- min(tip_y) - dy * 4
  for (j in seq_along(col_labels)) {
    xc  <- col_x_data(j)
    rng <- col_ranges[[j]]
    pal <- col_pals[[j]]
    # 5-step colorbar drawn as 5 small squares stacked vertically
    n_steps <- 5
    sw <- col_w_in * data_per_in * 0.4
    sh <- dy * 0.35
    for (k in seq_len(n_steps)) {
      val <- rng[1] + (k - 0.5) / n_steps * (rng[2] - rng[1])
      idx <- pmax(1, ceiling(100 * (val - rng[1]) / (rng[2] - rng[1])))
      rect(xc - sw / 2,
           legend_y - sh * (n_steps - k),
           xc + sw / 2,
           legend_y - sh * (n_steps - k - 1),
           col = pal[idx], border = "grey40", lwd = 0.3)
    }
    text(xc, legend_y + sh * 0.4,
         sprintf("%.2g", rng[2]), adj = c(0.5, 0), cex = 0.55, col = "grey25")
    text(xc, legend_y - sh * n_steps - sh * 0.3,
         sprintf("%.2g", rng[1]), adj = c(0.5, 1), cex = 0.55, col = "grey25")
  }

  # Provenance note in bottom-left
  mtext(sprintf("n = %d species  ·  PC scores from cached phyl.pca (BM, corr)  ·  body & trophic: rfishbase v%s  ·  depth (not shown): xlsx layered",
                n_tips, packageVersion("rfishbase")),
        side = 1, line = 2.6, cex = 0.65, col = "grey35", adj = 0)

  dev.off()
  invisible(out_pdf)
}

Tunable parameters

Parameter Default Effect
show_every_n 2 1 = every tip gets an image (use for trees with ≤60 tips); 3 or more = sparser image strip for very large trees
image_width_in (auto) clamp(0.6 * sqrt(60 / n_tips), 0.25, 1.2) Override by editing the helper if your images have an unusual aspect ratio
w, h 28, 24 Match these to the poster panel; for an 11”×17” handout reduce to w=11, h=17

How to swap traits

The 5 trait columns are defined inside plot_phylogeny_with_traits() as parallel lists (col_labels, col_pals, col_ranges, col_values). To replace “Body (cm)” with, say, “Depth max”, just edit those four lists in the helper — the layout is data-driven from there.
