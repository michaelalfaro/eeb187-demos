Workflow Overview

Bundle Export -> pavo classify (cached) -> Run 4 Recipes -> Hero PDFs -> Poster


  1. Bundle export – Students download their clade’s FishView bundle (HYBRID layout)
  2. pavo classify – Already cached as pavo_classify.rds and phylo_pca.rds (saves ~15 min)
  3. Run 4 recipes – Each recipe ends with a hero-PDF chunk. Run it!
  4. Generate hero PDFs – Four PDFs appear in figures/
  5. Drop into poster – Insert the PDFs into the 48”x36” PowerPoint template
  6. Fill text – Write Intro, Methods, Discussion, Conclusions around the figures

Each recipe is self-contained. Students do NOT need to understand the full codebase – just run the chunks in order, then grab the hero PDF at the end.

SECTION 2: Color Gamut (Panel A)

Recipe: Color Gamut – What colors does your clade have?

POSTER PANEL A – This figure goes in the top-left of your Results column (12”x9”). QUESTION: What is the extent of color diversity in your family?

What this recipe does:

  1. Loads the cached pavo::classify output (cluster centers for each species)
  2. Drops the background cluster using bg_class_id from the annotation file
  3. Pools all surviving cluster centers across the clade into the RGB cube
  4. Computes the 3D convex hull volume as a fraction of the unit RGB cube
  5. Plots a Stoddard-style faceted polyhedron with wireframe reference cube

Key output: A single number (gamut volume as % of RGB cube) plus a 3D scatter

Code – Loading pavo Data

# Setup: load packages and annotation file
library(tidyverse)
library(pavo)
library(geometry)
library(scatterplot3d)

BUNDLE <- "../../bundle"

ann <- read.csv(file.path(BUNDLE, "species_k_bg.csv"),
                stringsAsFactors = FALSE)
bg  <- setNames(ann$bg_class_id, ann$species_dir)

# Load the CACHED classify output (no need to re-run pavo!)
classified <- readRDS(file.path(BUNDLE, "pavo_classify.rds"))
cat(sprintf("Loaded %d classified images from cache.\n",
            length(classified)))

This reads the cached pavo::classify output. Students do NOT need to re-run pavo. The live classify call is commented out in the recipe – it takes 10-15 minutes.

Code – Extracting Cluster Centers

# Extract non-background cluster centers as RGB triples
get_palette <- function(rimg_obj, bg_id) {
  rgb_mat <- attr(rimg_obj, "classRGB")   # k x 3 matrix
  if (is.null(rgb_mat)) return(NULL)
  if (!is.na(bg_id) && bg_id >= 1 && bg_id <= nrow(rgb_mat)) {
    rgb_mat <- rgb_mat[-bg_id, , drop = FALSE]  # DROP background
  }
  rgb_mat
}

# Pool all cluster centers across species
palettes <- mapply(
  function(rimg_obj, sp) {
    p <- get_palette(rimg_obj, bg[gsub(" ", "_", sp)])
    if (is.null(p)) return(NULL)
    data.frame(species = sp, R = p[,"R"], G = p[,"G"], B = p[,"B"])
  },
  classified, names(classified), SIMPLIFY = FALSE
)
palettes <- bind_rows(palettes)

Each species contributes k - 1 color points (minus the magenta background). Pool them all to get the clade’s “color cloud” in RGB space.

Code – Building the Gamut

# Compute the 3D convex hull of all cluster centers
pts  <- as.matrix(palettes[, c("R", "G", "B")])
hull <- convhulln(pts, options = "FA")
vol  <- hull$vol

cat(sprintf("Gamut volume: %.4f of unit RGB cube (%.1f%%)\n",
            vol, 100 * vol))

What the number means:

  • Volume = 0.0 – All species are the same color (grey diagonal)
  • Volume = 1.0 – Clade fills the entire RGB cube (pure reds, greens, blues)
  • Typical reef fish families: 0.05 – 0.25

The convex hull is the smallest polyhedron enclosing all color points. The wireframe cube is the theoretical maximum.

The Output – What It Looks Like

The figure shows a Stoddard-style 3D RGB scatter:

  • Wireframe = unit RGB cube (theoretical maximum color space)
  • Semi-transparent facets = convex hull of your clade’s cluster centers
  • Colored points = individual cluster centers, colored by their RGB triple

For Chaetodontidae:

  • The clade lives mostly in the yellow-orange-brown corner
  • Extensions into bright white (unbarred body color) and dark black (contrast bars)
  • Gamut volume is relatively small – butterflyfishes have a narrow chromatic range

Students should look for: Where in the cube does their clade live? Is the hull compact (narrow palette) or spread out (chromatic diversity)?

SECTION 3: Phylomorphospace (Panel B)

Recipe: Phylomorphospace – How is color variation structured?

POSTER PANEL B – This figure goes in the top-right of your Results column (12”x9”). QUESTION: What are the major axes of color-pattern variation, and how are species distributed?

What this recipe does:

  1. Loads the cached phylo_pca.rds – phylogenetic PCA of pavo metrics
  2. Extracts PC1 and PC2 scores (typically ~60% of total variation)
  3. Estimates internal-node positions via phytools::fastAnc (Brownian motion)
  4. Plots each tip as its exemplar fish image (not a dot!)
  5. Draws phylogenetic edges connecting tips through reconstructed ancestors

This IS the phylomorphospace – the classic Sidlauskas/Revell visualization.

Code – Loading PhyloPCA

library(ape)
library(phytools)
library(png)

BUNDLE  <- "../../bundle"
IMG_DIR <- file.path(BUNDLE, "images")

# Load cached PCA + tree
pp   <- readRDS(file.path(BUNDLE, "phylo_pca.rds"))
ppca <- pp$ppca
tree <- pp$tree

S    <- ppca$S
PC1  <- setNames(S[, 1], rownames(S))
PC2  <- setNames(S[, 2], rownames(S))

eig  <- diag(ppca$Eval)
ve   <- 100 * eig / sum(eig)

cat(sprintf("PC1 var: %.1f%%   PC2 var: %.1f%%\n", ve[1], ve[2]))

PC1 and PC2 together capture ~60% of variation in pavo color-pattern metrics. The loading arrows (top 3 per axis) tell you what biological features each axis represents.

Code – Plotting with Fish Images

# Helper: read PNG and make magenta background transparent
read_fish_png <- function(path) {
  img <- readPNG(path)
  if (length(dim(img)) == 3) {
    if (dim(img)[3] == 3) {
      img <- array(c(img, rep(1, prod(dim(img)[1:2]))),
                   dim = c(dim(img)[1:2], 4))
    }
    # Make magenta pixels transparent
    mag <- img[,,1] > 0.8 & img[,,2] < 0.3 & img[,,3] > 0.8
    img[,,4][mag] <- 0
  }
  img
}

# Auto-size images based on number of tips
n_species <- length(tree$tip.label)
image_width_in <- max(0.25, min(1.2,
                     0.6 * sqrt(60 / n_species)))

Each species is plotted as its actual photo, not a dot. The magenta background removal is automatic. Image size auto-scales – 30 tips get big icons, 200 tips get small ones.

Code – Phylogenetic Edges + Ancestral Nodes

# Brownian ASR for each axis
anc1 <- fastAnc(tree, PC1)
anc2 <- fastAnc(tree, PC2)

# Combine tip + node coordinates
n_tips <- length(tree$tip.label)
coords <- matrix(NA_real_, nrow = n_tips + tree$Nnode,
                 ncol = 2)
coords[1:n_tips, 1] <- PC1[tree$tip.label]
coords[1:n_tips, 2] <- PC2[tree$tip.label]
coords[(n_tips+1):nrow(coords), 1] <- anc1[...]
coords[(n_tips+1):nrow(coords), 2] <- anc2[...]

# Draw edges: parent -> child through the tree
for (e in seq_len(nrow(tree$edge))) {
  segments(coords[tree$edge[e,1], 1], ...,
           coords[tree$edge[e,2], 1], ...,
           col = "grey55", lwd = 0.6)
}

Grey lines connect species through their reconstructed ancestors – this IS the phylomorphospace. Long edges = rapid evolution. Crossing edges are normal (2D projection of a high-dimensional process).

Reading the Phylomorphospace

How to interpret the figure:

  • Tips far from the centroid = species with extreme color-pattern signatures
  • Long edges = lineages that moved a lot in morphospace per million years
  • Short edges connecting nearby points = evolutionary stasis
  • Clusters of similar-looking fish = convergence on the leading PC axes
  • Crossing edges are expected – they reflect projection from high dimensions

Tell students: “Look for clusters of similar-looking fish far from the center. Those represent convergent evolution on extreme color patterns. Look for isolated species connected by long edges – those are evolutionary outliers.”

SECTION 4: Phylogeny + Traits (Panel C)

Recipe: Phylogeny + Traits – THE HERO PANEL

POSTER PANEL C – THE BIGGEST PANEL on the poster (28”x24”). This is the visual centerpiece. QUESTION: How has color evolved along the tree? Is there phylogenetic signal?

What this recipe builds:

  1. Ladderized chronogram with branches colored by PC1 ASR (contMap)
  2. Exemplar fish images at tips (every other tip by default)
  3. Five trait columns to the right: PC1, PC2, PC3, Trophic level, Body size
  4. Each column uses filled circles with color-encoded values

This is the most information-dense figure on the poster. Give it the most space.

Code – PC1 Ancestral State Reconstruction

# contMap: continuous trait mapped onto branches
cm1 <- contMap(tree, PC1, plot = FALSE, res = 200)
cm1 <- setMap(cm1, colors = c("#2c7bb6",  # blue (low)

Branch colors show reconstructed PC1 values:

  • Blue branches = low pattern density (simple, few-patch patterns)
  • Red branches = high pattern density (complex, many-patch patterns)
  • Color transitions along a branch = evolutionary change in PC1

Look for clades where branch color shifts dramatically – those are where evolution happened fastest. Uniform-colored clades = evolutionary stasis on PC1.

SECTION 5: PGLS (Panel D)

Recipe: PGLS – Does ecology predict color?

POSTER PANEL D – This figure goes in the right column (12”x24”, full height). QUESTION: After controlling for phylogeny, do trophic level or body size predict color-pattern variation?

What this recipe does:

  1. Builds a data frame with PC1, PC2, trophic_level, log(body_size_cm) for each species
  2. Fits PGLS with nlme::gls using corPagel correlation structure
  3. Extracts partial residuals for each predictor
  4. Plots a 2x2 grid of partial-residual scatters with stats in the corner

Output: Four scatter panels stacked vertically (PC1 vs trophic, PC1 vs body, PC2 vs trophic, PC2 vs body)

What is PGLS?

The problem: Related species share traits because of common ancestry. Regular regression treats each species as independent – this inflates sample size and can produce false positives.

The solution: PGLS (Phylogenetic Generalized Least Squares) models the expected covariance between species residuals using the phylogeny.

Pagel’s lambda (in the model):

  • lambda = 0: Phylogeny does not matter (residuals are independent)
  • lambda = 1: Full Brownian motion (related species have strongly correlated residuals)
  • lambda is estimated from the data – it tells you how much phylogeny matters

“Regular regression assumes independence. PGLS accounts for the fact that related species share traits because of common ancestry, not just ecology.”

Code – Fitting PGLS

library(nlme)

fit_pgls <- function(response_col) {
  f <- as.formula(
    sprintf("%s ~ trophic_level + log_body", response_col))

  # Try several lambda starting values (optimizer is fragile)
  starts <- c(0.5, 0.9, 0.1, 0.99, 0.0)
  for (lam0 in starts) {
    m <- tryCatch(
      nlme::gls(f, data = df_use,
                correlation = ape::corPagel(lam0, tree_use,
                               form = ~species, fixed = FALSE),
                method = "ML"),
      error = function(e) NULL)
    if (!is.null(m)) return(m)
  }
}

m_pc1 <- fit_pgls("PC1")
m_pc2 <- fit_pgls("PC2")

If the model fails to converge, the recipe tries multiple starting values automatically. If ALL fail, it falls back to fixed lambda = 1 (Brownian).

Code – Partial Residual Plots

# Partial residuals: response minus the contribution of
# "other" predictors, so each scatter shows the ISOLATED
# effect of the focal predictor.

pr_data <- function(m, focal, response_col) {
  b <- coef(m)
  fitted_other <- 0
  for (term in setdiff(names(b),
                       c("(Intercept)", focal))) {
    fitted_other <- fitted_other +
                    b[term] * df_use[[term]]
  }
  y_partial <- df_use[[response_col]] - fitted_other
  data.frame(species = df_use$species,
             x = df_use[[focal]],
             y = y_partial)
}

pr_PC1_trophic <- pr_data(m_pc1, "trophic_level", "PC1")
pr_PC1_body    <- pr_data(m_pc1, "log_body",      "PC1")

These show the PARTIAL effect of each predictor – the relationship after removing the other predictor’s effect. The fitted line has the PGLS slope (not OLS).

The Output – What It Looks Like

The hero PDF is a 4-panel stack:

  1. PC1 vs Trophic level – Does diet predict pattern density?
  2. PC1 vs log(Body size) – Does body size predict pattern density?
  3. PC2 vs Trophic level – Does diet predict color diversity?
  4. PC2 vs log(Body size) – Does body size predict color diversity?

Each panel has in the corner:

  • coef = the PGLS slope (direction + magnitude of the relationship)
  • SE = standard error
  • p = p-value (is it significant?)
  • lambda = estimated Pagel’s lambda

Points are colored by genus so you can spot if one genus is driving the signal.

SECTION 6: Writing the Poster Text

Writing Your Poster Text

The figures tell the story. The text FRAMES the story.

Golden rule: A viewer should understand your main finding from the hero figure + conclusion bullets alone (the 6-foot rule). The text sections add context and nuance.

Text budget for a 48”x36” poster:

Section Word count Sentences
Introduction 80-120 words 3-4 sentences
Research Question 1-2 sentences
Hypothesis 2-3 bullets
Methods 5-6 bullets
Discussion 80-120 words 3-4 sentences
Conclusions 2-3 bullets
Future Directions 1-2 bullets
Acknowledgments 2-3 sentences
References 5-7 citations

Introduction Template

Fill in the blanks:

“[YOUR FAMILY] ([common name]) are a family of [N] species distributed across [geographic range]. They exhibit [describe color pattern variation in 1 sentence]. Color patterns in fishes serve multiple ecological functions including [2-3 functions: crypsis, aposematism, mate recognition, species recognition, social signaling]. We used quantitative image analysis (pavo) and phylogenetic comparative methods to investigate [1-sentence version of your question].”

Tips:

  • Lead with the biology, not the methods
  • Name the family and give species count
  • End with your specific question
  • 3-4 sentences MAX – this is a poster, not a paper

Research Question + Hypothesis

Research Question: “How are color patterns distributed across the phylogeny of [YOUR FAMILY], and do ecological traits (trophic level, body size) predict color-pattern variation after controlling for shared ancestry?”

Hypothesis: “If color patterns in [YOUR FAMILY] are primarily shaped by [ecological selection / drift / phylogenetic conservatism], then we predict:

  1. Phylogenetic signal in color PCs will be [high (K > 1) / moderate (K ~ 1) / low (K < 1)]
  2. [Trophic level / body size] will [significantly / not significantly] predict color-pattern variation in PGLS
  3. The gamut volume will be [large / small] relative to other reef fish families”

State ONE question. Then state testable predictions. The predictions should connect to specific panels on the poster.

Methods Template

Methods (as a bullet list):

  • Image source: Standardized exemplar images from FishView (n = [N] species), exported as HYBRID-layout PNGs
  • Color analysis: pavo::classify with k = [range] clusters per species; cluster centers pooled for gamut computation
  • Phylogenetic PCA: phytools::phyl.pca on [X] pavo adjacency metrics under Brownian correlation
  • Phylogenetic signal: Blomberg’s K and Pagel’s lambda for PC1-PC3 (phytools::phylosig)
  • PGLS: nlme::gls with corPagel correlation structure; PC1 and PC2 regressed on trophic level + log(body size)
  • Tree: [N]-tip chronogram from Brownstein et al. (2025), pruned to exemplar species

Keep it to 5-6 bullets. The code is in the recipes – the poster just summarizes.

Discussion + Conclusions

Discussion (lead with your main finding):

“Color patterns in [YOUR FAMILY] show [strong/moderate/weak] phylogenetic signal (K = [value] for PC1, lambda = [value]). The gamut volume of [X.XXX] indicates a [narrow/broad] chromatic range compared to [other families / Alfaro et al. 2019 benchmarks]. [Trophic level / body size] [was / was not] a significant predictor of color-pattern variation after controlling for phylogeny (PGLS: coef = [value], p = [value], lambda = [value]). This suggests that [ecological selection / phylogenetic conservatism / neutral evolution] plays a [primary / secondary] role in shaping color patterns in this family.”

Conclusions (2-3 bullets):

  • Color patterns in [FAMILY] are [conserved/labile], with [K interpretation]
  • [Trait] [does/does not] predict color after controlling for phylogeny (p = [value])
  • Compared to butterflyfishes (Alfaro et al. 2019), [FAMILY] shows [more/less/similar] color diversity

References – Every Poster Should Cite These

Final Checklist

Common Mistakes

Mistake Fix
Wall of text Cut to 3-4 sentences per section. Let figures carry the story.
Too many figures Stick to the 4 hero panels. A K-value table is not a figure.
Unlabeled axes Every axis gets name + units. “PC1” alone is not enough – say “PC1 (chromatic boundary strength, 68% var)”
Default R styling Use poster-sized fonts (base_size = 20). Remove gray backgrounds.
Tiny figure text Re-export with larger cex or base_size. Check at actual poster dimensions.
Buried key result State your main finding in the title or as a callout in Results.
Inconsistent colors Same genus = same color in every figure. Pick a palette, stick to it.
Missing captions Every figure needs a self-contained caption below it.
No hypothesis State predictions BEFORE the results. Connect each prediction to a panel.
Lambda not reported Always report Pagel’s lambda alongside PGLS p-values.
Wrong page size Poster must be 48”x36” landscape. Check before exporting to PDF.

Common error fixes:

  • “Error in keep.tip” -> Species names don’t match between your tree and your trait CSV. Check underscores vs spaces.
  • “Error in corPagel” -> PGLS optimizer failed. The recipe tries 5 starting values automatically, but if all fail, check for invariant predictors or extreme outliers.
  • “Error in readRDS” -> Cache file not found. Re-run the classify or phyl.pca step (takes 10-15 min).
  • “Error in rasterImage” -> PNG file missing. Check that bundle/images/ has the expected species PNGs.
