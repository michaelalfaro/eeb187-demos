Recipe 26: Rate-Trait Correlation

Do faster-diversifying lineages in my family have different color patterns?

The Big Question

Do faster-diversifying lineages in my family have different color patterns?

This Is an Instance Of…

Rate-phenotype correlation

This analysis tests whether species that belong to fast-diversifying lineages differ systematically in their color patterns from species in slow-diversifying lineages. It bridges two domains of macroevolutionary analysis: diversification rate estimation (how fast lineages generate new species) and phenotypic evolution (how color patterns vary across the tree). A significant relationship would suggest that color and speciation are linked — either because color divergence promotes reproductive isolation and thus speciation, or because the same ecological factors that drive speciation also reshape color patterns.

Why This Matters for Your Clade

The central question of your project is how color pattern diversity arose. If faster-diversifying lineages have systematically more complex (or simpler, or different) color patterns, that tells you something fundamental about the relationship between color and speciation in your family. It moves your poster beyond describing color variation to explaining it in the context of species diversification.

Clade-specific tips
  • Pomacanthidae (angelfishes): The species-rich Centropyge may show different color metrics than less diverse genera. If fast-diversifying Centropyge have lower transition density (simpler patterns), this suggests diversification favors streamlined phenotypes.
  • Cirrhilabrini (fairy wrasses): If the species-rich Cirrhilabrus have higher color complexity AND higher diversification rates, this is consistent with sexual selection driving both color elaboration and speciation.
  • Balistoidea (triggerfishes + filefishes): Monacanthidae have more species than Balistidae. Does this higher diversity correlate with different color patterns? The rate-trait correlation will tell you.
  • Scarinae (parrotfishes): If terminal-phase color complexity correlates with diversification rate, color display may play a role in reproductive isolation.

The Method

This recipe combines ClaDS1 tip-specific speciation rates (from Recipe 21) with pavo color metrics in a phylogenetic generalized least squares (PGLS) regression. PGLS accounts for the non-independence of species due to shared ancestry — essential because both speciation rates and color traits are phylogenetically structured.

The analysis proceeds in three steps. First, extract tip-specific speciation rates from your ClaDS1 results (you must have run Recipe 21 first). Second, merge these rates with your pavo color metrics. Third, use safe_pgls() from helpers.R to test whether log-transformed speciation rate predicts each color variable. We log-transform rates because speciation rates are typically right-skewed, and the log transformation improves the linearity of the relationship.

A significant positive slope means faster-diversifying lineages have higher values of that color metric. A significant negative slope means faster-diversifying lineages have lower values. No significance means diversification rate and color evolve independently.

How to Interpret Results

Result Interpretation What to say on your poster
Positive slope, p < 0.05 Faster-diversifying lineages have MORE complex/conspicuous color “Species in rapidly diversifying lineages show higher color complexity, suggesting color may drive or accompany speciation in this family.”
Negative slope, p < 0.05 Faster-diversifying lineages have SIMPLER/less conspicuous color “Faster diversification is associated with simpler color patterns, suggesting that rapid speciation in this family does not require color elaboration.”
p > 0.05 No detectable relationship “Diversification rate and color pattern evolve independently — the tempo of speciation does not predict color complexity.”
Significant for some variables but not others Color dimensions differ in their link to diversification “The link between diversification and color is trait-specific: [variable X] correlates with speciation rate while [variable Y] does not.”
Common pitfalls
  • Correlation does not equal causation. Even a significant result does not tell you the direction of causality. Does color drive speciation (e.g., through reproductive isolation)? Or does rapid speciation drive color divergence (e.g., through character displacement)? Or does a third factor (ecology, habitat) drive both? State the correlation and discuss possible causal mechanisms, but do not claim causation.
  • You must have run Recipe 21 (ClaDS1) first. This recipe depends on tip-specific speciation rates from ClaDS. If you have not run ClaDS, go do that first.
  • Tip rates from ClaDS have uncertainty. The MAP estimates used here are point estimates from a posterior distribution. Ideally, you would propagate uncertainty by repeating the analysis across posterior samples, but for a course project the MAP estimates are sufficient.
  • PGLS corrects for phylogenetic non-independence. Do not use ordinary least squares (OLS) for this analysis — species are not independent data points. The safe_pgls() function handles this automatically.
  • Log-transforming rates is important. Speciation rates are right-skewed (most species have low rates, a few have high rates). Using raw rates can produce misleading regressions driven by a few fast-diversifying outliers. Always use log(rate).

The Code

# ── Recipe 26: Rate-Trait Correlation ─────────────────────────────
# DEPENDS ON: Recipe 21 (ClaDS1) — you must have tip rates ready.

source("https://michaelalfaro.github.io/eeb187-demos/recipes/code/helpers.R")   # loads ape, phytools, ggplot2, theme_poster

# ── 1. Load your tree and pavo data ───────────────────────────────
bundle   <- load_bundle("path/to/your-family-mini-bundle")
pavo_csv <- read.csv("path/to/your-pavo-metrics.csv",
                      stringsAsFactors = FALSE)

matched <- match_tree_data(bundle$tree, pavo_csv, species_col = "species")
tree    <- matched$tree
traits  <- matched$data

# ── 2. Load ClaDS1 tip rates from Recipe 21 ──────────────────────
# Option A: Load from CSV saved in Recipe 21
tip_rate_df <- read.csv("results/clads1-tip-rates.csv",
                         stringsAsFactors = FALSE)

# Option B: Re-extract from saved ClaDS result (if CSV not available)
# clads1_res   <- readRDS("results/clads1-result.rds")
# maps         <- getMAPS_ClaDS(clads1_res, burn = 1/2, thin = 1)
# branch_rates <- maps[-(1:4)]
# n_tips       <- length(tree$tip.label)
# tip_edges    <- which(tree$edge[, 2] <= n_tips)
# tip_rates    <- branch_rates[tip_edges]
# names(tip_rates) <- tree$tip.label[tree$edge[tip_edges, 2]]
# tip_rate_df  <- data.frame(species = names(tip_rates),
#                             rate = tip_rates,
#                             stringsAsFactors = FALSE)

# ── 3. Merge tip rates with pavo metrics ─────────────────────────
rate_df <- data.frame(
  species = tip_rate_df$species,
  speciation_rate = tip_rate_df$rate,
  log_rate = log(tip_rate_df$rate),
  stringsAsFactors = FALSE
)

merged <- merge(traits, rate_df, by = "species")
cat("Merged data:", nrow(merged), "species with both rates and pavo\n")

# ── 4. Match to tree ─────────────────────────────────────────────
matched2 <- match_tree_data(tree, merged, species_col = "species")
tree2    <- matched2$tree
dat2     <- matched2$data

# ── 5. PGLS: does speciation rate predict color complexity? ──────
# Start with transition density (m)
cat("\n── PGLS: m ~ log(speciation rate) ──────────────────────────\n")
model_m <- safe_pgls(m ~ log_rate, df = dat2, tree = tree2)

# ── 6. Scatter plot for transition density (m) ───────────────────
ggplot(dat2, aes(x = log_rate, y = m)) +
  geom_point(size = 4, alpha = 0.7, color = "#264653") +
  geom_smooth(method = "lm", color = "#e76f51", linewidth = 1.2,
              se = TRUE) +
  labs(title = "Do faster-diversifying lineages have more complex color?",
       x = "log(Speciation rate) from ClaDS1",
       y = "Transition density (m)") +
  theme_poster

ggsave("results/recipe26-rate-vs-m.pdf", width = 8, height = 6)
cat("Saved: results/recipe26-rate-vs-m.pdf\n")

# ── 7. Run for all 6 pavo variables ──────────────────────────────
pavo_vars <- c("m", "A", "Jc", "Jt", "m_dS", "m_dL")

rate_trait_summary <- data.frame(
  Variable   = character(0),
  Slope      = numeric(0),
  SE         = numeric(0),
  t_value    = numeric(0),
  p_value    = numeric(0),
  Direction  = character(0),
  stringsAsFactors = FALSE
)

for (v in pavo_vars) {
  # Build formula dynamically
  frm <- as.formula(paste(v, "~ log_rate"))

  pgls_fit <- tryCatch(
    safe_pgls(frm, df = dat2, tree = tree2),
    error = function(e) {
      message(v, ": PGLS failed — ", e$message)
      NULL
    }
  )

  if (!is.null(pgls_fit)) {
    coefs <- summary(pgls_fit)$tTable
    sl    <- coefs["log_rate", "Value"]
    se    <- coefs["log_rate", "Std.Error"]
    tv    <- coefs["log_rate", "t-value"]
    pv    <- coefs["log_rate", "p-value"]

    direction <- "No relationship"
    if (pv < 0.05 && sl > 0) direction <- "Positive"
    if (pv < 0.05 && sl < 0) direction <- "Negative"

    rate_trait_summary <- rbind(rate_trait_summary, data.frame(
      Variable  = v,
      Slope     = round(sl, 4),
      SE        = round(se, 4),
      t_value   = round(tv, 3),
      p_value   = round(pv, 4),
      Direction = direction,
      stringsAsFactors = FALSE
    ))
  }
}

cat("\n── Rate-Trait Correlation Summary ──────────────────────────\n")
print(rate_trait_summary, row.names = FALSE)

# ── 8. Six-panel scatter plot ─────────────────────────────────────
library(gridExtra)

plot_list <- list()
for (v in pavo_vars) {
  p <- ggplot(dat2, aes(x = log_rate, y = .data[[v]])) +
    geom_point(size = 3, alpha = 0.6, color = "#264653") +
    geom_smooth(method = "lm", color = "#e76f51",
                linewidth = 1, se = TRUE) +
    labs(title = v,
         x = "log(Speciation rate)",
         y = v) +
    theme_poster +
    theme(plot.title = element_text(size = 14))
  plot_list[[v]] <- p
}

pdf("results/recipe26-rate-trait-all.pdf", width = 14, height = 10)
grid.arrange(grobs = plot_list, ncol = 3)
dev.off()
cat("Saved: results/recipe26-rate-trait-all.pdf\n")

# ── 9. Highlight significant results ─────────────────────────────
sig_vars <- rate_trait_summary$Variable[rate_trait_summary$p_value < 0.05]
if (length(sig_vars) > 0) {
  cat("\nSignificant rate-trait correlations found for:",
      paste(sig_vars, collapse = ", "), "\n")
  cat("These color variables are associated with diversification rate.\n")
} else {
  cat("\nNo significant rate-trait correlations detected.\n")
  cat("Diversification rate and color appear to evolve independently.\n")
}
