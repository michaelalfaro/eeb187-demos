Recipe 18: Biogeographic Color Variation

Does color pattern diversity differ between ocean basins?

The Big Question

Do species from the Atlantic show different color pattern diversity than Indo-Pacific species in the same family, or does the ocean basin a lineage lives in have no detectable influence on color evolution?

This Is an Instance Of…

Biogeographic comparison / natural experiment

Ocean basins are among the most powerful natural experiments in evolutionary biology. The closure of the Isthmus of Panama ~3 million years ago separated Atlantic and Pacific populations of the same ancestral lineages, and the deep break between the Atlantic and Indo-Pacific goes back much further. By treating basin as a categorical predictor in a phylogenetic model, you are asking whether the evolutionary and ecological context of each basin — different species richness, different competitors, different light environments — has pushed color patterns in detectably different directions. This is the comparative method applied to geography rather than ecology.

Why This Matters for Your Clade

The Atlantic and Indo-Pacific differ dramatically in reef fish diversity, habitat complexity, and the ecological roles color plays. The Indo-Pacific hosts far more reef fish species, potentially driving greater diversification of color signals for species recognition. The Atlantic, with fewer species, may rely less on fine-grained color discrimination. Testing this hypothesis with pavo metrics turns a qualitative observation into a quantifiable claim.

Clade-specific tips
  • Halichoerine wrasses (tribe Julidini and relatives): Several genera contain geminate species pairs — Atlantic sister species separated from Pacific relatives by the Isthmus of Panama. These pairs are a particularly clean biogeographic signal because the divergence time is known (~3 Mya). If your bundle contains Halichoeres or Thalassoma species from both basins, you have a textbook natural experiment.
  • Scarinae (parrotfishes): Sparisoma is almost entirely Atlantic; Scarus is almost entirely Indo-Pacific. This means your basin comparison is partly confounded with genus-level differences. Phrase your interpretation carefully: you are comparing Atlantic Sparisoma-grade color to Indo-Pacific Scarus-grade color, not controlling for that evolutionary split.
  • Pomacanthidae (angelfishes): Several genera (e.g., Centropyge, Holacanthus) have Atlantic and Indo-Pacific representatives. Make sure your basin coding reflects the actual range of each species, not just the genus home range.
  • Balistoidea (triggerfishes + filefishes): Several triggerfish genera span both basins. Check FishBase range maps for each species individually; do not assume genus-level distribution.

The Method

You have two ways to assign species to basins. Option A (recommended) is to code basin by hand from range maps. Open FishBase or your reference literature, look at each species’ known range, and write a two-column CSV with species and basin (values: Atlantic, Indo-Pacific, or both). This takes 30–60 minutes but gives you accurate, defensible assignments. Species coded both — those that genuinely span both basins — should be excluded, because they do not test the question.

Option B uses FishBase’s stocks() function to pull geographic bounding boxes for each species and classifies them by longitude. This is faster but less reliable: FishBase bounding boxes can be imprecise, and some widespread species get misclassified. If you use Option B, spot-check at least a quarter of your assignments against known range maps.

Once basins are assigned, you run a PGLS with basin as a categorical predictor and your color metric of interest (typically Jc, color diversity) as the response. PGLS controls for the non-independence introduced by shared ancestry, so your basin comparison is not inflated by the fact that Atlantic species share an evolutionary history with each other independent of basin effects.

How to Interpret Results

Result Interpretation What to say on your poster
Significant basin effect (p < 0.05), Atlantic > Indo-Pacific Atlantic species show higher color diversity per species, possibly because fewer species must be distinguished via color “Color pattern diversity is unexpectedly higher in the Atlantic despite lower overall species richness.”
Significant basin effect (p < 0.05), Indo-Pacific > Atlantic Greater color diversity in the species-rich Indo-Pacific, consistent with species recognition pressure “Color pattern diversity tracks regional species richness, with Indo-Pacific species showing significantly more complex color patterns.”
Non-significant basin effect (p > 0.05) Basin does not predict color pattern diversity once phylogeny is accounted for “Ocean basin does not significantly predict color diversity, suggesting color evolution in this family is driven by factors other than regional species richness.”
Small or unequal sample sizes Results unreliable regardless of p-value Report both group sizes and interpret cautiously.
Common pitfalls
  • Unequal sample sizes per basin will affect power. If you have 40 Indo-Pacific species and 8 Atlantic species, a non-significant result may simply reflect low power in the smaller group. Always report n per basin in your poster.
  • Do not exclude both species silently. Report how many species you dropped as both and why. If more than 20% of your sample is excluded, the remaining comparison may be non-representative.
  • Basin is partly confounded with phylogeny. Atlantic and Indo-Pacific lineages often diverged deep in the tree, meaning basin and clade are correlated. PGLS mitigates but does not fully eliminate this — be honest about this limitation.
  • FishBase bounding boxes (Option B) can misclassify species. If you use the automated approach, validate a random subset and report how many species you hand-checked.

The Code

# ── Recipe 18: Biogeographic Color Variation ────────────────────
source("https://michaelalfaro.github.io/eeb187-demos/recipes/code/helpers.R")   # loads ape, phytools, ggplot2, theme_poster

# ── 1. Load your tree and pavo data ─────────────────────────────
bundle   <- load_bundle("path/to/your-family-mini-bundle")
pavo_csv <- read.csv("path/to/your-pavo-metrics.csv",
                      stringsAsFactors = FALSE)

# ── 2A. Option A (recommended): hand-coded basin assignments ────
# Create a CSV with two columns: species, basin
# basin values: "Atlantic", "Indo-Pacific", or "both"
# Example row: Halichoeres_bivittatus, Atlantic
basins <- read.csv("my_basin_codes.csv", stringsAsFactors = FALSE)

# Merge with pavo metrics
merged <- merge(pavo_csv, basins, by = "species")

# Exclude species that span both basins
n_both <- sum(merged$basin == "both")
cat("Excluding", n_both, "species coded as 'both'\n")
merged <- merged[merged$basin != "both", ]

# Report sample sizes per basin
cat("Atlantic species:", sum(merged$basin == "Atlantic"), "\n")
cat("Indo-Pacific species:", sum(merged$basin == "Indo-Pacific"), "\n")

# ── 2B. Option B (automated, less reliable): FishBase ranges ────
# Uncomment this block if you prefer automated assignment.
# library(rfishbase)
# stocks_data <- rfishbase::stocks(pavo_csv$species)
# stocks_data <- stocks_data[!duplicated(stocks_data$Species), ]
# stocks_data$basin <- ifelse(
#   stocks_data$EasternLongitude < -20 & stocks_data$WesternLongitude > -100,
#   "Atlantic",
#   ifelse(stocks_data$WesternLongitude >= 20, "Indo-Pacific", "both")
# )
# merged <- merge(pavo_csv,
#                 stocks_data[, c("Species", "basin")],
#                 by.x = "species", by.y = "Species")
# merged <- merged[merged$basin != "both", ]

# ── 3. Match tree to merged data ────────────────────────────────
matched <- match_tree_data(bundle$tree, merged, species_col = "species")
tree    <- matched$tree
dat     <- matched$data

cat("Final sample:", length(tree$tip.label), "species\n")

# ── 4. PGLS: Jc ~ basin ─────────────────────────────────────────
model <- safe_pgls(Jc ~ basin, df = dat, tree = tree)
summary(model)

# Extract key numbers for the poster
coefs <- summary(model)$tTable
cat("\n── PGLS result ──\n")
cat("basin effect estimate:", round(coefs["basinIndo-Pacific", "Value"], 3), "\n")
cat("p-value:", round(coefs["basinIndo-Pacific", "p-value"], 4), "\n")

# ── 5. Boxplot with jittered points ─────────────────────────────
ggplot(dat, aes(x = basin, y = Jc, fill = basin)) +
  geom_boxplot(alpha = 0.7, outlier.shape = NA) +
  geom_jitter(width = 0.15, size = 3, alpha = 0.6) +
  labs(
    title = "Color diversity by ocean basin",
    x     = "",
    y     = "Color diversity (Jc)"
  ) +
  scale_fill_manual(
    values = c("Atlantic" = "#0077b6", "Indo-Pacific" = "#e76f51")
  ) +
  theme_poster +
  theme(legend.position = "none")

ggsave("results/recipe18-basin-boxplot.pdf", width = 7, height = 6)
cat("Saved: results/recipe18-basin-boxplot.pdf\n")

# ── 6. Optional: run for all 6 pavo variables ───────────────────
pavo_vars <- c("m", "A", "Jc", "Jt", "m_dS", "m_dL")
basin_results <- data.frame(
  Variable = character(0),
  estimate = numeric(0),
  p_value  = numeric(0),
  stringsAsFactors = FALSE
)

for (v in pavo_vars) {
  formula_str <- paste(v, "~ basin")
  mod <- tryCatch(
    safe_pgls(as.formula(formula_str), df = dat, tree = tree),
    error = function(e) NULL
  )
  if (!is.null(mod)) {
    tt <- summary(mod)$tTable
    row_name <- grep("basin", rownames(tt), value = TRUE)[1]
    basin_results <- rbind(basin_results, data.frame(
      Variable = v,
      estimate = round(tt[row_name, "Value"], 3),
      p_value  = round(tt[row_name, "p-value"], 4),
      stringsAsFactors = FALSE
    ))
  }
}
cat("\n── Basin effects across all pavo variables ──\n")
print(basin_results)
