Recipe 24: Node Heights Test for Rate Trends

Have rates of color pattern evolution accelerated or decelerated through my family’s history?

The Big Question

Have rates of color pattern evolution accelerated or decelerated through my family’s history?

This Is an Instance Of…

Temporal rate trend detection

The node heights test asks whether the magnitude of evolutionary change is correlated with when that change occurred. It works by computing phylogenetic independent contrasts (PICs) — standardized measures of how much a trait changed at each node — and regressing their absolute values against node age. A significant negative slope means larger changes happened earlier in the tree’s history (deceleration, consistent with early burst or niche filling). A significant positive slope means larger changes happened recently (acceleration). No slope means rates have been constant, consistent with Brownian motion. This is a simple, powerful diagnostic that complements model-based approaches (Recipes 19 and 20) with a regression-based test.

Why This Matters for Your Clade

Model comparison (Recipe 20/22) tells you which evolutionary model best fits the data, but it does not show you the pattern visually. The node heights test produces a scatter plot that makes the temporal trend (or lack of one) immediately visible. A steep negative slope says “the big color changes happened millions of years ago, and recent evolution has been fine-tuning.” A positive slope says “the real action is recent.” Either way, you get a figure that tells a clear story on your poster and complements your DTT (Recipe 19) and model comparison results.

Clade-specific tips
  • Pomacanthidae (angelfishes): If the deep split between Pomacanthus and Centropyge drove most color divergence, expect a negative slope (deceleration). Recent speciation within Centropyge might involve small color shifts.
  • Cirrhilabrini (fairy wrasses): Ongoing sexual selection could maintain high rates of color change at recent nodes, producing a flat or positive slope — contrasting with families where color evolution has slowed.
  • Balistoidea (triggerfishes + filefishes): The deep family-level split should produce a large early contrast. If within-family evolution is modest, expect a clear negative slope.
  • Hypsigenyinae (hogfishes and allies): With ~38 species, you have relatively few contrasts. The regression may lack power, so report the trend direction even if p > 0.05.

The Method

Phylogenetic independent contrasts (PICs) measure how much a trait changed at each node in the tree, standardized by the expected amount of change given the branch lengths. The absolute value of each contrast tells you the magnitude of evolutionary change at that node, regardless of direction.

The node heights test regresses these absolute contrast values against node ages (measured as time before the present). Under Brownian motion (constant rates), there should be no relationship — the magnitude of change should be the same whether a node is old or young. A significant slope indicates that rates are not constant.

This test was introduced by Freckleton and Harvey (2006) as a diagnostic for non-Brownian evolution in adaptive radiations. It is conceptually simple (just a linear regression), visually intuitive (a scatter plot), and directly interpretable. It is also implemented in the geiger package as nh.test(), but we build it manually here so you can customize the plot for your poster.

How to Interpret Results

Slope p < 0.05? Interpretation What to say on your poster
Negative Yes Rates decelerated — early burst of color evolution “The largest color changes occurred early in the family’s history, with rates decelerating toward the present. This is consistent with early ecological or phenotypic niche filling.”
Negative No Trend toward deceleration, but not significant “There is a trend toward early burst, but it is not statistically significant. Rates are consistent with Brownian motion.”
Positive Yes Rates accelerated — late burst of color evolution “Rates of color evolution have increased toward the present, suggesting recent diversification in color is faster than early diversification.”
Positive No Trend toward acceleration, but not significant “There is a non-significant trend toward acceleration, consistent with constant-rate Brownian motion.”
Near zero No No temporal trend “Rates of color evolution show no temporal trend, consistent with constant-rate drift (Brownian motion).”
Common pitfalls
  • Small sample sizes reduce power. Each internal node produces one contrast, so a tree with N tips gives N-1 contrasts. With fewer than 30 contrasts, the regression may not detect real trends. Report the slope direction even when p > 0.05.
  • The test assumes contrasts are independent. This is guaranteed by the PIC algorithm when the tree is correct, but violations of the Brownian motion assumption (the very thing you are testing for) can introduce non-independence. Treat this as a diagnostic tool, not a definitive test.
  • Node ages must be correct. This test requires a time-calibrated (ultrametric) tree. Errors in divergence time estimates will distort the x-axis and can create spurious trends.
  • Outlier contrasts can drive the regression. A single very large contrast at a deep node can create a significant negative slope even if the rest of the tree is constant-rate. Inspect the scatter plot for influential points.

The Code

# ── Recipe 24: Node Heights Test for Rate Trends ──────────────────
source("https://michaelalfaro.github.io/eeb187-demos/recipes/code/helpers.R")   # loads ape, phytools, ggplot2, theme_poster

# ── 1. Load your tree and pavo data ───────────────────────────────
bundle   <- load_bundle("path/to/your-family-mini-bundle")
pavo_csv <- read.csv("path/to/your-pavo-metrics.csv",
                      stringsAsFactors = FALSE)

# ── 2. Match tree to data ─────────────────────────────────────────
matched <- match_tree_data(bundle$tree, pavo_csv, species_col = "species")
tree    <- matched$tree
dat     <- matched$data

cat("Working with", length(tree$tip.label), "species\n")

# ── 3. Check ultrametric ──────────────────────────────────────────
if (!ape::is.ultrametric(tree)) {
  cat("Forcing ultrametric tree (small numerical correction)\n")
  tree <- phytools::force.ultrametric(tree, method = "extend")
}

# ── 4. Node heights test for transition density (m) ───────────────
trait_vec <- setNames(dat$m, dat$species)
trait_vec <- trait_vec[tree$tip.label]

# Compute phylogenetic independent contrasts
contrasts <- pic(trait_vec, tree)

# Get node ages (time from root to each internal node)
node_ages <- branching.times(tree)

# Match contrasts to node ages (both are named by node number)
ages <- node_ages[names(contrasts)]

# Regress |PIC| against node age
model <- lm(abs(contrasts) ~ ages)
s     <- summary(model)

cat("\n── Node Heights Test: transition density (m) ───────────────\n")
cat("Slope:", round(coef(model)[2], 4), "\n")
cat("p-value:", format.pval(s$coefficients[2, 4], digits = 3), "\n")
cat("R-squared:", round(s$r.squared, 3), "\n")

if (coef(model)[2] < 0 && s$coefficients[2, 4] < 0.05) {
  cat("→ Significant DECELERATION: rates were higher early in clade history\n")
} else if (coef(model)[2] > 0 && s$coefficients[2, 4] < 0.05) {
  cat("→ Significant ACCELERATION: rates increased toward the present\n")
} else {
  cat("→ No significant temporal trend in rates\n")
}

# ── 5. Plot ───────────────────────────────────────────────────────
pic_df <- data.frame(age = ages, abs_pic = abs(contrasts))

ggplot(pic_df, aes(x = age, y = abs_pic)) +
  geom_point(size = 3, alpha = 0.6, color = "#264653") +
  geom_smooth(method = "lm", color = "#e76f51", linewidth = 1.2, se = TRUE) +
  labs(title = "Node Heights Test: rate trend through time",
       subtitle = paste0("Slope = ", round(coef(model)[2], 4),
                        ", p = ", format.pval(s$coefficients[2, 4], digits = 3)),
       x = "Node age (millions of years before present)",
       y = "|Phylogenetic independent contrast|") +
  theme_poster

ggsave("results/recipe24-node-heights-m.pdf", width = 8, height = 6)
cat("Saved: results/recipe24-node-heights-m.pdf\n")

# ── 6. Run for all 6 pavo variables ──────────────────────────────
pavo_vars <- c("m", "A", "Jc", "Jt", "m_dS", "m_dL")

# Remove species with missing data
complete     <- complete.cases(dat[, pavo_vars])
dat_complete <- dat[complete, ]
tree_sub     <- ape::drop.tip(tree,
                              setdiff(tree$tip.label, dat_complete$species))

nh_summary <- data.frame(
  Variable = character(0),
  Slope    = numeric(0),
  p_value  = numeric(0),
  R_sq     = numeric(0),
  Direction = character(0),
  stringsAsFactors = FALSE
)

for (v in pavo_vars) {
  x <- setNames(dat_complete[[v]], dat_complete$species)
  x <- x[tree_sub$tip.label]

  con    <- pic(x, tree_sub)
  n_ages <- branching.times(tree_sub)[names(con)]
  mod    <- lm(abs(con) ~ n_ages)
  sm     <- summary(mod)
  sl     <- coef(mod)[2]
  pv     <- sm$coefficients[2, 4]

  direction <- "No trend"
  if (sl < 0 && pv < 0.05) direction <- "Deceleration"
  if (sl > 0 && pv < 0.05) direction <- "Acceleration"

  nh_summary <- rbind(nh_summary, data.frame(
    Variable  = v,
    Slope     = round(sl, 4),
    p_value   = round(pv, 4),
    R_sq      = round(sm$r.squared, 3),
    Direction = direction,
    stringsAsFactors = FALSE
  ))
}

cat("\n── Node Heights Test Summary (all 6 pavo variables) ───────\n")
print(nh_summary, row.names = FALSE)

# ── 7. Six-panel scatter plot ─────────────────────────────────────
pdf("results/recipe24-node-heights-all.pdf", width = 12, height = 8)
par(mfrow = c(2, 3))
for (v in pavo_vars) {
  x <- setNames(dat_complete[[v]], dat_complete$species)
  x <- x[tree_sub$tip.label]

  con    <- pic(x, tree_sub)
  n_ages <- branching.times(tree_sub)[names(con)]
  mod    <- lm(abs(con) ~ n_ages)
  sm     <- summary(mod)

  plot(n_ages, abs(con),
       pch = 16, col = "#264653", cex = 1.2,
       xlab = "Node age (Myr)", ylab = "|PIC|",
       main = v)
  abline(mod, col = "#e76f51", lwd = 2)
  mtext(paste0("slope=", round(coef(mod)[2], 3),
               " p=", round(sm$coefficients[2, 4], 3)),
        side = 3, line = -1.5, adj = 0.05, cex = 0.8)
}
dev.off()
cat("Saved: results/recipe24-node-heights-all.pdf\n")

From the Literature

Freckleton, R. P., & Harvey, P. H. (2006) — Introduced the node heights test as a diagnostic for non-Brownian trait evolution in adaptive radiations. By regressing the absolute values of phylogenetic independent contrasts against node depth, they showed that niche-filling models produce a characteristic negative slope (deceleration). Applied the test to feeding adaptations in warbler radiations. PLoS Biology, 4(11), e373. DOI

Harmon, L. J., Losos, J. B., Davies, T. J., Gillespie, R. G., Gittleman, J. L., Jennings, W. B., … & Mooers, A. O. (2010) — Used the node heights test alongside DTT and model comparison in a large-scale survey of early burst evolution, providing context for how commonly deceleration is detected across diverse clades. Evolution, 64(8), 2385–2396. DOI
