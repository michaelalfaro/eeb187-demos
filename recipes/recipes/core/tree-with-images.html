Recipe: Tree with Species Images

Visualize your phylogeny with fish photos at the tips

Plot your phylogenetic tree with species photographs at each tip, labeled with italic binomials — in both rectangular and circular (fan) layouts.

This is an instance of…

Phylogenetic visualization. A tree with images at the tips is the most intuitive way to show your audience what your study organisms look like and how they’re related. It’s often the first figure on a poster — it grounds every other result in the biology.

Why This Matters for Your Clade

Every group has exemplar images from FishView. Plotting them on the tree immediately reveals whether similar-looking species are close relatives (phylogenetic signal in appearance) or scattered across the tree (convergence). This figure also shows your audience the organisms before you hit them with statistics.

Parrotfish and wrasse groups

Your images are mostly terminal-phase males. Plotting them on the tree makes the IP/TP color difference vivid — if you have any IP images mixed in, they’ll stand out immediately as the drab outliers.

The Method

This recipe uses base R phylogenetic plotting (ape::plot.phylo()) with rasterImage() to overlay PNG images at tip coordinates. No special packages beyond ape, phytools, and png are needed.

The approach:

  1. Load and normalize the tree (strip specimen codes to clean Genus_species)
  2. Find the exemplar image for each species in the bundle’s images/ directory
  3. Plot the tree without tip labels
  4. Overlay each species’ photo at its tip position
  5. Add an italic species name below each image

We show two layouts: rectangular (best for posters where you need to read species names) and fan/circle (best for showing many species compactly).

How to Interpret the Figure

This is a visualization recipe, not a statistical test. But look for:

Pattern What it suggests
Similar-looking species clustered together Color pattern has phylogenetic signal — close relatives look alike
Similar colors scattered across the tree Convergent evolution — distantly related species evolved similar appearances
One subclade looks dramatically different Possible adaptive radiation in color, or a shift in ecology/habitat
Obvious outlier (drab among colorful) May be a juvenile or IP individual mixed into your dataset — check it

The Code

Setup: Load packages and prepare the tree

library(ape)
library(phytools)
library(png)

# Helper: read PNG and make magenta background transparent
read_fish_png <- function(path) {
  img <- readPNG(path)
  if (length(dim(img)) == 3) {
    if (dim(img)[3] == 3) {
      img <- array(c(img, rep(1, prod(dim(img)[1:2]))),
                   dim = c(dim(img)[1:2], 4))
    }
    mag <- img[,,1] > 0.7 & img[,,2] < 0.4 & img[,,3] > 0.7
    img[,,4][mag] <- 0
  }
  img
}

# ── 1. Load and normalize the tree ──────────────────────────────
# Point this to YOUR bundle directory
bundle_dir <- "path/to/your/bundle"

# Find the tree file — accepts both the new "<family>-tree.tre" name
# emitted by the hybrid bundle exporter and the legacy "-mini-tree.tre".
tree_file <- list.files(bundle_dir, pattern = "-tree\\.tre$",
                        full.names = TRUE)[1]
tree <- tryCatch(read.nexus(tree_file),
                 error = function(e) read.tree(tree_file))
if (inherits(tree, "multiPhylo")) tree <- tree[[1]]

# Normalize tip labels to Genus_species (strip specimen codes)
to_binomial <- function(tips) {
  vapply(tips, function(t) {
    parts <- strsplit(t, "_", fixed = TRUE)[[1]]
    if (length(parts) < 2) return(parts[1])
    genus   <- parts[1]
    species <- sub("^([a-z]+).*", "\\1", parts[2])
    paste(genus, species, sep = "_")
  }, character(1), USE.NAMES = FALSE)
}

tree$tip.label <- to_binomial(tree$tip.label)

# Drop duplicate tips (keeps first occurrence)
dups <- duplicated(tree$tip.label)
if (any(dups)) tree <- drop.tip(tree, tree$tip.label[dups])

# ── 2. Find species with images (HYBRID bundle layout) ─────────
# The bundle's images/ directory contains BOTH a flat exemplar
#   images/Genus_species.png
# and a per-species folder
#   images/Genus_species/exemplar.png + img-N.png
# Use the flat files as the authoritative list of species; fall back
# to the folder's exemplar.png for legacy nested-only bundles.
img_dir <- file.path(bundle_dir, "images")
flat_files <- list.files(img_dir,
                         pattern = "^[A-Z][a-z]+_[a-z]+\\.png$",
                         full.names = TRUE, recursive = FALSE)
if (length(flat_files) > 0) {
  img_species <- tools::file_path_sans_ext(basename(flat_files))
  exemplar_lookup <- setNames(flat_files, img_species)
} else {
  # Legacy nested-only fallback
  subdirs <- list.dirs(img_dir, recursive = FALSE)
  has_ex  <- subdirs[file.exists(file.path(subdirs, "exemplar.png"))]
  img_species <- basename(has_ex)
  exemplar_lookup <- setNames(file.path(has_ex, "exemplar.png"), img_species)
}

# Keep only species that are in BOTH the tree AND the image directory
keep <- intersect(tree$tip.label, img_species)
cat(length(keep), "species with both tree tip and image\n")

tree_img <- drop.tip(tree, setdiff(tree$tip.label, keep))

# ── 3. Build a named list of image paths ───────────────────────
img_paths <- exemplar_lookup[tree_img$tip.label]

# Check all exist (should always be true at this point — sanity check)
missing <- names(img_paths)[!file.exists(img_paths)]
if (length(missing) > 0) {
  cat("Warning: missing image file for:", paste(missing, collapse = ", "), "\n")
  img_paths <- img_paths[file.exists(img_paths)]
  tree_img <- drop.tip(tree_img, missing)
}

Rectangular tree with images

# ── 4a. Rectangular tree with images ───────────────────────────

n_tips     <- length(tree_img$tip.label)
tree_depth <- max(node.depth.edgelength(tree_img))

# Reserve right side for images
x_max <- tree_depth * 1.65

# Plot the tree (no tip labels — we'll add them under the images)
par(mar = c(2, 1, 3, 1), xpd = NA)
plot(tree_img,
     show.tip.label = FALSE,
     no.margin = FALSE,
     x.lim = c(0, x_max),
     y.lim = c(0.5, n_tips + 0.5),
     edge.width = 2.5,
     edge.color = "#333333")
title(main = "Your family on the tree", cex.main = 1.4)

# Get tip coordinates from the last plot
pp <- get("last_plot.phylo", envir = .PlotPhyloEnv)

# Image sizing
img_h <- min(0.85, 0.9 * max(1, 3 / n_tips))   # height in tip-row units
img_w <- 0.35 * tree_depth                       # width in tree-depth units
x_left <- tree_depth + 0.04 * tree_depth         # small gap past branch tips
x_right <- x_left + img_w

# Overlay images and labels
for (i in seq_along(tree_img$tip.label)) {
  tip <- tree_img$tip.label[i]
  if (!(tip %in% names(img_paths))) next

  img <- read_fish_png(img_paths[tip])
  tip_y <- pp$yy[i]

  rasterImage(img,
              xleft = x_left,
              ybottom = tip_y - img_h / 2,
              xright = x_right,
              ytop = tip_y + img_h / 2,
              interpolate = TRUE)

  # Italic species name below the image
  label <- gsub("_", " ", tip)
  text(x = (x_left + x_right) / 2,
       y = tip_y - img_h / 2 - 0.08,
       labels = label,
       font = 3, cex = 0.7, adj = c(0.5, 1))
}

Fan (circle) tree with images

# ── 4b. Fan (circle) tree with images ─────────────────────────

# For a fan layout, images are placed radially around the tree.
# We use phytools::plotTree with type="fan" and manually compute
# polar coordinates for each image.

par(mar = c(1, 1, 3, 1), xpd = NA)
plot(tree_img,
     type = "fan",
     show.tip.label = FALSE,
     no.margin = FALSE,
     edge.width = 2.5,
     edge.color = "#333333",
     open.angle = 10)     # small gap at the bottom
title(main = "Your family — fan layout", cex.main = 1.4)

# Get tip coordinates (these are already in Cartesian x,y for the fan)
pp <- get("last_plot.phylo", envir = .PlotPhyloEnv)

# Image size in plot units — scale relative to the tree radius
tree_radius <- max(sqrt(pp$xx^2 + pp$yy^2))
img_size <- tree_radius * 0.12   # adjust this to change image size

for (i in seq_along(tree_img$tip.label)) {
  tip <- tree_img$tip.label[i]
  if (!(tip %in% names(img_paths))) next

  img <- read_fish_png(img_paths[tip])

  # Tip position in the fan
  tx <- pp$xx[i]
  ty <- pp$yy[i]

  # Push image outward from the tip along the radial direction
  angle <- atan2(ty, tx)
  offset <- tree_radius * 0.08   # gap between branch tip and image
  cx <- tx + cos(angle) * offset
  cy <- ty + sin(angle) * offset

  # Aspect ratio of the image
  asp <- ncol(img) / nrow(img)
  half_w <- img_size * asp / 2
  half_h <- img_size / 2

  rasterImage(img,
              xleft   = cx - half_w,
              ybottom = cy - half_h,
              xright  = cx + half_w,
              ytop    = cy + half_h,
              interpolate = TRUE)

  # Species label below the image (slightly further out)
  label <- gsub("_", " ", tip)
  label_r <- offset + img_size * 1.1
  lx <- tx + cos(angle) * label_r
  ly <- ty + sin(angle) * label_r

  # Rotate text to follow the angle (readable orientation)
  angle_deg <- angle * 180 / pi
  adj <- if (abs(angle_deg) > 90) c(1, 0.5) else c(0, 0.5)
  if (abs(angle_deg) > 90) angle_deg <- angle_deg + 180

  text(lx, ly, labels = label,
       srt = angle_deg, font = 3, cex = 0.55, adj = adj)
}

Save as PDF

Poster tip

The rectangular layout works best when you have fewer than ~25 species (the images stay large enough to see). For 30+ species, use the fan layout — it packs more species into the same space. Export as PDF for perfect scaling on your poster.

Worked Example: Chaetodontidae

Here is the complete code to produce both trees from the Chaetodontidae mini-bundle (the Demo 8 walkthrough dataset). You can run this as-is to test the recipe before adapting it to your own clade.

# ── Worked example: Chaetodontidae butterflyfishes ─────────────
library(ape)
library(phytools)
library(png)

bundle_dir <- "path/to/chaetodontidae-bundle"  # ← update this path

# Load tree (accepts both "<family>-tree.tre" and legacy "-mini-tree.tre")
tree_file <- list.files(bundle_dir, pattern = "-tree\\.tre$",
                        full.names = TRUE)[1]
tree <- read.tree(tree_file)
if (inherits(tree, "multiPhylo")) tree <- tree[[1]]

# Normalize tips
to_binomial <- function(tips) {
  vapply(tips, function(t) {
    parts <- strsplit(t, "_", fixed = TRUE)[[1]]
    if (length(parts) < 2) return(parts[1])
    paste(parts[1], sub("^([a-z]+).*", "\\1", parts[2]), sep = "_")
  }, character(1), USE.NAMES = FALSE)
}
tree$tip.label <- to_binomial(tree$tip.label)
dups <- duplicated(tree$tip.label)
if (any(dups)) tree <- drop.tip(tree, tree$tip.label[dups])

# Find species with images — HYBRID layout: prefer flat exemplars under
# images/Genus_species.png, fall back to nested images/Genus_species/exemplar.png
img_dir <- file.path(bundle_dir, "images")
flat_files <- list.files(img_dir,
                         pattern = "^[A-Z][a-z]+_[a-z]+\\.png$",
                         full.names = TRUE, recursive = FALSE)
if (length(flat_files) > 0) {
  img_species <- tools::file_path_sans_ext(basename(flat_files))
  exemplar_lookup <- setNames(flat_files, img_species)
} else {
  subdirs <- list.dirs(img_dir, recursive = FALSE)
  has_ex  <- subdirs[file.exists(file.path(subdirs, "exemplar.png"))]
  img_species <- basename(has_ex)
  exemplar_lookup <- setNames(file.path(has_ex, "exemplar.png"), img_species)
}
keep <- intersect(tree$tip.label, img_species)
tree_img <- drop.tip(tree, setdiff(tree$tip.label, keep))

img_paths <- exemplar_lookup[tree_img$tip.label]
exists_mask <- file.exists(img_paths)
if (!all(exists_mask)) {
  cat("Skipping (no image):", paste(names(img_paths)[!exists_mask], collapse=", "), "\n")
  img_paths <- img_paths[exists_mask]
  tree_img <- drop.tip(tree_img, setdiff(tree_img$tip.label, names(img_paths)))
}

n_tips <- length(tree_img$tip.label)
tree_depth <- max(node.depth.edgelength(tree_img))
cat(n_tips, "butterflyfishes with images on tree\n")

# ── Rectangular PDF ──
pdf("chaet-tree-rectangular.pdf", width = 14, height = max(8, n_tips * 0.55))
x_max <- tree_depth * 1.65
par(mar = c(2, 1, 3, 1), xpd = NA)
plot(tree_img, show.tip.label = FALSE, no.margin = FALSE,
     x.lim = c(0, x_max), y.lim = c(0.5, n_tips + 0.5),
     edge.width = 2.5, edge.color = "#333333")
title("Chaetodontidae — rectangular tree with images", cex.main = 1.4)
pp <- get("last_plot.phylo", envir = .PlotPhyloEnv)
img_h <- min(0.85, 0.9 * max(1, 3 / n_tips))
img_w <- 0.35 * tree_depth
x_left <- tree_depth + 0.04 * tree_depth
x_right <- x_left + img_w
for (i in seq_along(tree_img$tip.label)) {
  tip <- tree_img$tip.label[i]
  img <- read_fish_png(img_paths[tip])
  tip_y <- pp$yy[i]
  rasterImage(img, x_left, tip_y - img_h/2, x_right, tip_y + img_h/2,
              interpolate = TRUE)
  text((x_left + x_right)/2, tip_y - img_h/2 - 0.08,
       gsub("_", " ", tip), font = 3, cex = 0.7, adj = c(0.5, 1))
}
dev.off()
cat("Saved: chaet-tree-rectangular.pdf\n")

# ── Fan PDF ──
pdf("chaet-tree-fan.pdf", width = 14, height = 14)
par(mar = c(1, 1, 3, 1), xpd = NA)
plot(tree_img, type = "fan", show.tip.label = FALSE, no.margin = FALSE,
     edge.width = 2.5, edge.color = "#333333", open.angle = 10)
title("Chaetodontidae — fan tree with images", cex.main = 1.4)
pp <- get("last_plot.phylo", envir = .PlotPhyloEnv)
tree_radius <- max(sqrt(pp$xx^2 + pp$yy^2))
img_size <- tree_radius * 0.12
for (i in seq_along(tree_img$tip.label)) {
  tip <- tree_img$tip.label[i]
  img <- read_fish_png(img_paths[tip])
  tx <- pp$xx[i]; ty <- pp$yy[i]
  angle <- atan2(ty, tx)
  offset <- tree_radius * 0.08
  cx <- tx + cos(angle) * offset
  cy <- ty + sin(angle) * offset
  asp <- ncol(img) / nrow(img)
  half_w <- img_size * asp / 2; half_h <- img_size / 2
  rasterImage(img, cx - half_w, cy - half_h, cx + half_w, cy + half_h,
              interpolate = TRUE)
  label <- gsub("_", " ", tip)
  label_r <- offset + img_size * 1.1
  lx <- tx + cos(angle) * label_r
  ly <- ty + sin(angle) * label_r
  angle_deg <- angle * 180 / pi
  adj <- if (abs(angle_deg) > 90) c(1, 0.5) else c(0, 0.5)
  if (abs(angle_deg) > 90) angle_deg <- angle_deg + 180
  text(lx, ly, label, srt = angle_deg, font = 3, cex = 0.55, adj = adj)
}
dev.off()
cat("Saved: chaet-tree-fan.pdf\n")
