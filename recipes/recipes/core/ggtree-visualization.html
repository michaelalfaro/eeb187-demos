Recipe 25: ggtree for Publication-Quality Phylogenies

How do I make a beautiful, data-rich phylogeny figure with colored branches and annotations?

The Big Question

How do I make a beautiful, data-rich phylogeny figure with colored branches, tip annotations, clade highlights, and aligned data panels?

This Is an Instance Of…

Phylogenetic data visualization

This is a visualization recipe — it does not test a hypothesis. Instead, it teaches you how to use ggtree, an extension of ggplot2 designed for phylogenetic trees, to produce poster-quality figures that combine tree topology with trait data. ggtree uses the same grammar-of-graphics approach as ggplot2, so if you are comfortable with aes(), geom_*, and theme(), you already know the syntax. The result is a figure that communicates both relationships and trait variation in a single, layered image.

Why This Matters for Your Clade

Your poster needs at least one phylogeny figure, and it needs to be beautiful. Base R tree plots (from ape::plot.phylo()) work for quick exploration, but they are difficult to customize for a poster. ggtree lets you color branches by trait values, add genus-colored tip points, highlight clades with transparent shading, annotate nodes, and combine the tree with bar charts or heatmaps in multi-panel layouts using patchwork. The figures you produce here will be the visual centerpieces of your poster.

Clade-specific tips
  • All groups: Start with Recipe E.1 (trait-colored branches) and Recipe E.4 (tree + bar chart). These two layouts work for every family.
  • Pomacanthidae (angelfishes) and Cirrhilabrini (fairy wrasses): Use the fan layout (Recipe E.2) to display many species compactly, with genus-colored tip points to highlight taxonomic structure.
  • Balistoidea (triggerfishes + filefishes): Use clade highlighting (Recipe E.3) to visually separate Balistidae from Monacanthidae on the tree.

The Method

ggtree is a Bioconductor package (not CRAN) that extends ggplot2 to handle phylogenetic tree objects. It converts a tree into a data frame of node coordinates, then plots branches, tips, and annotations as ggplot layers. You can overlay trait data using the %<+% operator, which joins a data frame to the tree by matching tip labels.

This recipe provides four visualization sub-recipes that build on each other:

  1. Trait-colored branches — color each branch by a continuous pavo variable using ancestral state reconstruction to extend values to internal branches.
  2. Fan layout with genus-colored tips — a circular tree with colored tip points, ideal for large trees.
  3. Clade highlighting — shade and label specific clades (genera, subfamilies) on the tree.
  4. Multi-panel: tree + bar chart — combine a phylogeny with an aligned bar chart of trait values using patchwork.
Installing ggtree

ggtree is a Bioconductor package. Install it with:

if (!requireNamespace("BiocManager", quietly = TRUE))
    install.packages("BiocManager")
BiocManager::install("ggtree")

You will also need tidytree (installed automatically with ggtree) and patchwork for multi-panel layouts: install.packages("patchwork").

How to Interpret the Figure

This is a visualization recipe, not a statistical test. But your figures should reveal:

Visual pattern What it suggests
Branches shift color at a specific node A major evolutionary transition in color pattern at that point in the tree
One clade is uniformly one color, another is different Genus-level or clade-level conservatism in color
Colors are scattered randomly across the tree Low phylogenetic signal — color is evolutionarily labile
Bar chart heights cluster by clade Trait values are phylogenetically structured
Bar chart heights are uniform across clades Trait has converged or is not phylogenetically structured
Common pitfalls
  • Trait-colored branches require ancestral state estimates. To color internal branches (not just tips), you need ancestral values from fastAnc() (Recipe 23). Without these, only tip branches will have colors.
  • Fan layout text overlaps. With more than ~50 species, tip labels in fan layout will overlap. Reduce size in geom_tiplab() or use geom_tippoint() alone and add a separate legend.
  • ggtree objects are ggplots. You can add any ggplot layer (+ theme(), + scale_color_*, etc.). But coord_flip() and coord_polar() do not work with tree layouts — use ggtree’s built-in layout parameter instead.
  • The %<+% operator is specific to ggtree. It joins a data frame to the tree data by matching the label column (tip labels). Make sure your data frame has a column called label that matches tree$tip.label.

The Code

Recipe E.1: Trait-colored branches (continuous variable)

# ── Recipe 25.1: Trait-colored branches ───────────────────────────
# Requires: ggtree (Bioconductor), viridis, phytools
# Install ggtree: BiocManager::install("ggtree")

source("../../code/helpers.R")   # loads ape, phytools, ggplot2, theme_poster
library(ggtree)
library(viridis)

# ── 1. Load tree and pavo data ────────────────────────────────────
bundle   <- load_bundle("path/to/your-family-mini-bundle")
pavo_csv <- read.csv("path/to/your-pavo-metrics.csv",
                      stringsAsFactors = FALSE)

matched <- match_tree_data(bundle$tree, pavo_csv, species_col = "species")
tree    <- matched$tree
dat     <- matched$data

# ── 2. Prepare trait vector and ancestral estimates ───────────────
trait_vec <- setNames(dat$m, dat$species)
trait_vec <- trait_vec[tree$tip.label]

# Ancestral state reconstruction for internal branches
asr <- fastAnc(tree, trait_vec, CI = TRUE)

# Combine tip and internal node values into one vector
# Node numbering: 1..N = tips, (N+1)..(N+Nnode) = internal
n_tips <- length(tree$tip.label)
all_values <- c(trait_vec[tree$tip.label], asr$ace)

# Build a data frame for ggtree: one row per node
tree_data <- data.frame(
  node  = 1:(n_tips + tree$Nnode),
  value = all_values
)

# ── 3. Plot trait-colored tree ────────────────────────────────────
p <- ggtree(tree, aes(color = value), linewidth = 1.2) %<+% tree_data +
  scale_color_viridis_c(name = "Transition\ndensity (m)",
                        option = "plasma") +
  geom_tiplab(size = 2.5, color = "black", offset = 0.5) +
  theme_tree2() +
  theme(legend.position = c(0.05, 0.85))
p

ggsave("results/recipe25-trait-colored-tree.pdf", p,
       width = 10, height = 12)
cat("Saved: results/recipe25-trait-colored-tree.pdf\n")

Recipe E.2: Fan layout with genus-colored tips

# ── Recipe 25.2: Fan layout with genus-colored tips ───────────────
library(ggtree)

# Build a genus data frame
genus_df <- data.frame(
  label = tree$tip.label,
  genus = sub("_.*", "", tree$tip.label),
  stringsAsFactors = FALSE
)

p_fan <- ggtree(tree, layout = "fan", linewidth = 0.8) %<+% genus_df +
  geom_tippoint(aes(color = genus), size = 3) +
  geom_tiplab(aes(color = genus), size = 2, offset = 0.3) +
  theme(legend.position = "right",
        legend.text = element_text(face = "italic"))
p_fan

ggsave("results/recipe25-fan-genus-colored.pdf", p_fan,
       width = 12, height = 12)
cat("Saved: results/recipe25-fan-genus-colored.pdf\n")

Recipe E.3: Highlight specific clades

# ── Recipe 25.3: Highlight clades ────────────────────────────────
library(ggtree)

# Start with a simple tree
p_base <- ggtree(tree, linewidth = 0.8) +
  geom_tiplab(size = 2.5, fontface = "italic")

# Highlight a genus — change "Chaetodon" to a genus in YOUR family
genus_name <- "Chaetodon"   # ← CHANGE THIS to a genus in your tree
genus_tips <- tree$tip.label[grepl(paste0("^", genus_name, "_"),
                                    tree$tip.label)]

if (length(genus_tips) >= 2) {
  mrca <- getMRCA(tree, genus_tips)

  p_highlight <- p_base +
    geom_hilight(node = mrca, fill = "#e9c46a",
                 alpha = 0.2, extend = 5) +
    geom_cladelab(node = mrca, label = genus_name,
                  fontsize = 5, offset = 3, barsize = 1.5,
                  color = "#e9c46a", fontface = "italic")
  p_highlight

  ggsave("results/recipe25-clade-highlight.pdf", p_highlight,
         width = 10, height = 12)
  cat("Saved: results/recipe25-clade-highlight.pdf\n")
} else {
  cat("Need at least 2 species in genus '", genus_name,
      "' to highlight a clade.\n")
  cat("Change genus_name to a genus with multiple species in your tree.\n")
}

Recipe E.4: Multi-panel — tree + bar chart

# ── Recipe 25.4: Multi-panel tree + bar chart ─────────────────────
# Requires: patchwork
# If not installed: install.packages("patchwork")

library(ggtree)
library(patchwork)

# ── Left panel: phylogeny ─────────────────────────────────────────
p_tree <- ggtree(tree, linewidth = 0.8) +
  geom_tiplab(size = 2.5, fontface = "italic")

# ── Right panel: bar chart of transition density ──────────────────
# IMPORTANT: species order must match the tree tip order in the plot
# get_taxa_name() extracts tips in the order they appear in the ggtree plot
tip_order <- rev(get_taxa_name(p_tree))

trait_bar <- data.frame(
  species = tree$tip.label,
  m       = trait_vec[tree$tip.label],
  stringsAsFactors = FALSE
)
trait_bar$species <- factor(trait_bar$species, levels = tip_order)

p_bar <- ggplot(trait_bar, aes(x = m, y = species)) +
  geom_col(fill = "#2a9d8f", alpha = 0.85) +
  labs(x = "Transition density (m)") +
  theme_minimal() +
  theme(axis.text.y = element_blank(),
        axis.title.y = element_blank(),
        panel.grid.major.y = element_blank())

# ── Combine with patchwork ────────────────────────────────────────
combined <- p_tree + p_bar + plot_layout(widths = c(3, 1))
combined

ggsave("results/recipe25-tree-plus-bar.pdf", combined,
       width = 12, height = max(8, length(tree$tip.label) * 0.3))
cat("Saved: results/recipe25-tree-plus-bar.pdf\n")
