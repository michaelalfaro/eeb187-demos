Recipe 23: Continuous Ancestral State Reconstruction

What color pattern did the ancestor of my family likely have, and how have traits changed along the phylogeny?

The Big Question

What color pattern did the ancestor of my family likely have, and how have traits changed along the phylogeny?

This Is an Instance Of…

Ancestral state estimation for continuous traits

Ancestral state reconstruction (ASR) uses the observed trait values at the tips of a phylogeny and a model of evolution (here, Brownian motion) to estimate the most likely trait values at internal nodes — including the root. This tells you what the ancestor probably looked like and identifies where on the tree the largest changes occurred. For continuous traits like pavo color metrics, maximum likelihood ASR produces point estimates with 95% confidence intervals at every internal node, letting you quantify uncertainty about ancestral phenotypes.

Why This Matters for Your Clade

Every poster tells a story about how color diversity arose. Ancestral state reconstruction lets you anchor that story at the root: “The ancestor of my family likely had [low/moderate/high] color complexity, and derived lineages evolved [toward/away from] that ancestral condition.” It also identifies which branches on the tree experienced the largest evolutionary changes, pointing you toward the lineages where color evolution was most dramatic.

Clade-specific tips
  • Pomacanthidae (angelfishes): Was the ancestor drab or colorful? If the root reconstruction is moderate and derived genera diverge in both directions, you have evidence for bidirectional evolution from a generalized ancestral pattern.
  • Cirrhilabrini (fairy wrasses): If the root value for color metrics like Jc (color adjacency) is low but tip values span a wide range, the ancestor was likely relatively plain and the spectacular male display colors are derived.
  • Balistoidea (triggerfishes + filefishes): Reconstruct the MRCA of each family separately — did triggerfishes and filefishes diverge from a similar ancestral color pattern, or were they already different at the split?
  • Scarinae (parrotfishes): The root value may reflect a more cryptic initial-phase-like pattern if early diverging species are less colorful, with terminal-phase brilliance evolving later.

The Method

We use phytools::fastAnc() to perform maximum likelihood ancestral state reconstruction under Brownian motion. This function estimates the trait value at every internal node that maximizes the likelihood of observing the tip data, given the tree topology and branch lengths. When called with CI = TRUE, it also returns 95% confidence intervals for each node estimate.

The root node estimate is the single most informative result — it tells you what the common ancestor of your entire family probably looked like for each color variable. But the internal node estimates are also valuable: by comparing a node’s value to its descendants’ values, you can identify where on the tree the biggest evolutionary shifts happened.

We complement the numerical estimates with contMap() visualizations, which paint the tree with a continuous color gradient showing how each trait changes from root to tips. The combination of numerical estimates (with CIs) and visual maps gives you both the precision to make quantitative claims and the visual impact needed for a poster.

How to Interpret Results

Pattern Interpretation What to say on your poster
Root value near center of tip range Ancestor was intermediate; derived lineages diverged in both directions “The ancestral color pattern was moderate, and descendent lineages evolved both increased and decreased complexity.”
Root value at one extreme Ancestor was at one end of the spectrum; evolution has been predominantly directional “The ancestor had [low/high] color complexity, and evolution has been predominantly toward [higher/lower] values.”
Narrow CI at root Confident reconstruction “We can reconstruct the ancestral condition with high confidence.”
Wide CI at root Uncertain reconstruction “The ancestral state is uncertain, reflecting the lability of color evolution in this family.”
Large jumps at specific nodes Major evolutionary shifts at particular branches “The largest color shifts occurred at the base of [clade X], suggesting a key transition in color strategy.”
Common pitfalls
  • ASR assumes Brownian motion by default. If your Recipe 20/22 results show that OU or another model fits better, the BM-based reconstruction may be biased. For OU-favored traits, consider that reconstructions near the root are pulled toward the OU optimum and may be overconfident.
  • Wide confidence intervals are the norm, not the exception. Deep nodes (near the root) accumulate uncertainty from both sides of the tree. A wide CI does not mean the analysis failed — it means the trait is genuinely uncertain at that point, which is itself informative.
  • Do not over-interpret small differences between nodes. If two internal nodes differ by 0.05 in transition density (m) but both have CIs spanning 0.3 units, that difference is not meaningful. Focus on large, CI-non-overlapping shifts.
  • Tip values drive everything. If your pavo data has errors at the tips, those errors propagate into the ancestral estimates. Double-check any species whose reconstructed value seems anomalous.

The Code

# ── Recipe 23: Continuous Ancestral State Reconstruction ──────────
source("https://michaelalfaro.github.io/eeb187-demos/recipes/code/helpers.R")   # loads ape, phytools, ggplot2, theme_poster

# ── 1. Load your tree and pavo data ───────────────────────────────
bundle   <- load_bundle("path/to/your-family-mini-bundle")
pavo_csv <- read.csv("path/to/your-pavo-metrics.csv",
                      stringsAsFactors = FALSE)

# ── 2. Match tree to data ─────────────────────────────────────────
matched <- match_tree_data(bundle$tree, pavo_csv, species_col = "species")
tree    <- matched$tree
dat     <- matched$data

cat("Working with", length(tree$tip.label), "species\n")

# ── 3. Check ultrametric ──────────────────────────────────────────
if (!ape::is.ultrametric(tree)) {
  cat("Forcing ultrametric tree (small numerical correction)\n")
  tree <- phytools::force.ultrametric(tree, method = "extend")
}

# ── 4. Ancestral state reconstruction for transition density (m) ──
trait_vec <- setNames(dat$m, dat$species)
trait_vec <- trait_vec[tree$tip.label]   # align to tree order

asr <- fastAnc(tree, trait_vec, CI = TRUE)

# Root estimate
cat("\n── Root Ancestral State ────────────────────────────────────\n")
cat("Estimated root value (m):", round(asr$ace[1], 3), "\n")
cat("95% CI:", round(asr$CI95[1, ], 3), "\n")
cat("Observed tip range:", round(range(trait_vec), 3), "\n")

# ── 5. Ancestral values at genus-level MRCAs ─────────────────────
# Get all genera in the tree
genera <- unique(sub("_.*", "", tree$tip.label))
n_tips <- length(tree$tip.label)

mrca_table <- data.frame(
  Genus        = character(0),
  N_species    = integer(0),
  MRCA_node    = integer(0),
  Ancestral_m  = numeric(0),
  CI_lower     = numeric(0),
  CI_upper     = numeric(0),
  stringsAsFactors = FALSE
)

for (g in genera) {
  genus_tips <- tree$tip.label[grepl(paste0("^", g, "_"), tree$tip.label)]
  if (length(genus_tips) < 2) next   # need at least 2 tips for an MRCA

  mrca_node <- getMRCA(tree, genus_tips)
  node_idx  <- mrca_node - n_tips   # internal node index for asr$ace

  mrca_table <- rbind(mrca_table, data.frame(
    Genus       = g,
    N_species   = length(genus_tips),
    MRCA_node   = mrca_node,
    Ancestral_m = round(asr$ace[node_idx], 3),
    CI_lower    = round(asr$CI95[node_idx, 1], 3),
    CI_upper    = round(asr$CI95[node_idx, 2], 3),
    stringsAsFactors = FALSE
  ))
}

cat("\n── Genus-Level Ancestral Estimates ─────────────────────────\n")
print(mrca_table, row.names = FALSE)

# ── 6. contMap visualization with labeled key nodes ───────────────
cm <- contMap(tree, trait_vec, plot = FALSE)

pdf("results/recipe23-contmap-m.pdf", width = 10, height = 10)
plot(cm, type = "fan", fsize = 0.5, lwd = 3,
     legend = 0.7 * max(nodeHeights(tree)))
title("Ancestral reconstruction: transition density (m)")

# Label key nodes with their estimated values
for (i in seq_len(nrow(mrca_table))) {
  nodelabels(text = round(mrca_table$Ancestral_m[i], 2),
             node = mrca_table$MRCA_node[i],
             bg = "white", cex = 0.6, frame = "rect")
}
dev.off()
cat("Saved: results/recipe23-contmap-m.pdf\n")

# ── 7. Six-panel figure: one contMap per pavo variable ────────────
pavo_vars <- c("m", "A", "Jc", "Jt", "m_dS", "m_dL")

# Remove species with missing data in any variable
complete <- complete.cases(dat[, pavo_vars])
dat_sub  <- dat[complete, ]
tree_sub <- ape::drop.tip(tree, setdiff(tree$tip.label, dat_sub$species))

pdf("results/recipe23-contmaps-all-variables.pdf", width = 14, height = 10)
par(mfrow = c(2, 3))
for (v in pavo_vars) {
  x <- setNames(dat_sub[[v]], dat_sub$species)
  x <- x[tree_sub$tip.label]

  cm_v <- contMap(tree_sub, x, plot = FALSE)
  plot(cm_v, type = "fan", fsize = 0.35, lwd = 2,
       legend = 0.6 * max(nodeHeights(tree_sub)))
  title(v, cex.main = 1.2)
}
dev.off()
cat("Saved: results/recipe23-contmaps-all-variables.pdf\n")

# ── 8. Summary table: root values for all 6 variables ────────────
root_summary <- data.frame(
  Variable  = character(0),
  Root_est  = numeric(0),
  CI_lower  = numeric(0),
  CI_upper  = numeric(0),
  Tip_min   = numeric(0),
  Tip_max   = numeric(0),
  stringsAsFactors = FALSE
)

for (v in pavo_vars) {
  x <- setNames(dat_sub[[v]], dat_sub$species)
  x <- x[tree_sub$tip.label]
  asr_v <- fastAnc(tree_sub, x, CI = TRUE)

  root_summary <- rbind(root_summary, data.frame(
    Variable = v,
    Root_est = round(asr_v$ace[1], 3),
    CI_lower = round(asr_v$CI95[1, 1], 3),
    CI_upper = round(asr_v$CI95[1, 2], 3),
    Tip_min  = round(min(x), 3),
    Tip_max  = round(max(x), 3),
    stringsAsFactors = FALSE
  ))
}

cat("\n── Root Ancestral Values for All 6 Color Variables ────────\n")
print(root_summary, row.names = FALSE)
