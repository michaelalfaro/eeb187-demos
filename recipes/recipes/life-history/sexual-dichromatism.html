Recipe: Sexual Dichromatism

How different are the sexes in color, and what drives that difference?

Tip

Life-History recipe. Asks: how large is the color difference between initial-phase (IP) and terminal-phase (TP) individuals, and does it vary with body size, depth, or reproductive ecology? Uses paired images of each species in both color phases, converts to CIELAB, and computes a Euclidean dichromatism index. The index is then mapped onto the phylogeny and tested against ecological predictors via PGLS.

Poster output. figures/dichromatism-paired-gamut-hero.pdf (10” x 10”) and figures/dichromatism-contmap-hero.pdf (14” x 32”). See Alternative Poster Type 5 for the full layout.

What you’re computing

Many reef fish families contain protogynous hermaphrodites — species that change sex from female to male. The two color phases are:

  • Initial phase (IP): females and primary males share a drab, often brown/red coloration.
  • Terminal phase (TP): dominant males display bright blues, greens, or complex patterns after sex change.

The magnitude of this color difference varies enormously across species. Some species (e.g., Leptoscarus vaigiensis) are monochromatic, while others (e.g., Scarus vetula) show dramatic TP-vs-IP contrast.

Dichromatism index = Euclidean distance between IP and TP centroids in CIELAB color space. This single number captures the perceptual magnitude of sexual dichromatism:

\[ d_{\text{dichro}} = \sqrt{(\Delta L^*)^2 + (\Delta a^*)^2 + (\Delta b^*)^2} \]

Because CIELAB is perceptually uniform, a distance of 10 units looks like roughly the same amount of change anywhere in the space. Typical values:

\(d_{\text{dichro}}\) Interpretation
0–5 Monochromatic — IP and TP are nearly identical
5–15 Weakly dichromatic — subtle hue or lightness shift
15–30 Moderately dichromatic — clearly different color phases
30+ Strongly dichromatic — dramatic IP/TP contrast

You can decompose the index into:

  • Chromatic distance (in the a*–b* plane): how different are the hues/saturations?
  • Lightness difference (\(\Delta L^*\)): how different are the brightnesses?

Helper functions

# Read a segmented PNG with magenta-background transparency
read_fish_png <- function(path) {
  img <- readPNG(path)
  if (length(dim(img)) == 3) {
    if (dim(img)[3] == 3) {
      img <- array(c(img, rep(1, prod(dim(img)[1:2]))),
                   dim = c(dim(img)[1:2], 4))
    }
    mag <- img[,,1] > 0.7 & img[,,2] < 0.4 & img[,,3] > 0.7
    img[,,4][mag] <- 0
  }
  img
}

# Extract foreground RGB from a segmented image
extract_fg_rgb <- function(path, sample_n = 5000) {
  img <- read_fish_png(path)
  h <- dim(img)[1]; w <- dim(img)[2]
  r <- as.vector(img[,,1])
  g <- as.vector(img[,,2])
  b <- as.vector(img[,,3])
  a <- as.vector(img[,,4])
  fg <- a > 0.5 &
    !(r > 0.7 & g < 0.4 & b > 0.7) &
    !(r < 0.02 & g < 0.02 & b < 0.02) &
    !(r > 0.98 & g > 0.98 & b > 0.98)
  rgb_fg <- cbind(R = r[fg], G = g[fg], B = b[fg])
  if (nrow(rgb_fg) > sample_n) {
    set.seed(42)
    rgb_fg <- rgb_fg[sample(nrow(rgb_fg), sample_n), ]
  }
  rgb_fg
}

# RGB matrix -> CIELAB matrix
rgb_to_lab <- function(rgb_mat) {
  srgb_obj <- colorspace::sRGB(rgb_mat[, "R"], rgb_mat[, "G"], rgb_mat[, "B"])
  lab_obj  <- as(srgb_obj, "LAB")
  coords   <- colorspace::coords(lab_obj)
  colnames(coords) <- c("L", "a", "b")
  coords
}

Classify IP and TP images

For each species, we extract the foreground pixel colors from the TP and IP exemplar images and convert them to CIELAB.

results <- list()

for (sp in species) {
  tp_path <- file.path(BUNDLE, "images", sp, "TP", "exemplar.png")
  ip_path <- file.path(BUNDLE, "images", sp, "IP", "exemplar.png")

  if (!file.exists(tp_path) || !file.exists(ip_path)) {
    message("Skipping ", sp, ": missing TP or IP image")
    next
  }

  tp_rgb <- extract_fg_rgb(tp_path)
  ip_rgb <- extract_fg_rgb(ip_path)
  if (nrow(tp_rgb) < 100 || nrow(ip_rgb) < 100) {
    message("Skipping ", sp, ": too few foreground pixels")
    next
  }

  tp_lab <- rgb_to_lab(tp_rgb)
  ip_lab <- rgb_to_lab(ip_rgb)

  results[[sp]] <- list(
    species = sp,
    tp_centroid = colMeans(tp_lab),
    ip_centroid = colMeans(ip_lab),
    tp_lab = tp_lab, ip_lab = ip_lab,
    tp_rgb = tp_rgb, ip_rgb = ip_rgb
  )
}
cat(sprintf("Processed %d species\n", length(results)))

Compute dichromatism index

dichro_df <- do.call(rbind, lapply(results, function(r) {
  d_full <- sqrt(sum((r$tp_centroid - r$ip_centroid)^2))
  d_chrom <- sqrt(sum((r$tp_centroid[c("a", "b")] -
                        r$ip_centroid[c("a", "b")])^2))
  d_L <- r$tp_centroid["L"] - r$ip_centroid["L"]

  data.frame(
    species        = r$species,
    dichro_idx     = d_full,
    chromatic_dist = d_chrom,
    L_diff         = d_L,
    TP_L = r$tp_centroid["L"], TP_a = r$tp_centroid["a"],
    TP_b = r$tp_centroid["b"],
    IP_L = r$ip_centroid["L"], IP_a = r$ip_centroid["a"],
    IP_b = r$ip_centroid["b"],
    stringsAsFactors = FALSE
  )
}))
rownames(dichro_df) <- NULL

cat("Dichromatism indices:\n")
print(dichro_df[, c("species", "dichro_idx", "chromatic_dist", "L_diff")])

Map dichromatism on phylogeny

Use phytools::contMap to reconstruct ancestral dichromatism values along the phylogeny.

# Match tree and dichromatism data
matched <- match_tree_data(tree, dichro_df, species_col = "species")
dichro_vec <- setNames(matched$data$dichro_idx, matched$data$species)
check_trait(dichro_vec, "dichro_idx", matched$tree)

# contMap
cm <- contMap(matched$tree, dichro_vec, plot = FALSE, res = 200)
cm <- setMap(cm, colors = c("#f7fcf5", "#74c476", "#238b45",
                             "#006d2c", "#00441b"))

plot(cm, fsize = 0.8, lwd = 3, outline = FALSE,
     legend = max(nodeHeights(matched$tree)) * 0.4)

How to interpret results

What you see What it means
High dichromatism index (>30) Dramatic color phase difference — strong candidate for sexual selection on male coloration
Low dichromatism index (<5) Minimal color difference between phases — monochromatic species or subtle dichromatism
IP cloud (warm) and TP cloud (cool) well separated IP and TP occupy different regions of color space — qualitatively different hues
IP and TP clouds overlapping Phases differ in lightness or saturation, not hue
Strong phylogenetic signal (K>1) Closely related species have similar dichromatism levels — the trait is phylogenetically conserved
Weak signal (K<1) Dichromatism evolves rapidly and independently across lineages
PGLS body size positive Larger species tend to be more dichromatic — consistent with size-advantage model of sex change
PGLS depth negative Shallower species are more dichromatic — consistent with visual signaling in clear water

Common pitfalls

Image phase assignment is critical

If you accidentally swap TP and IP labels for a species, the dichromatism index will still be computed correctly (distance is symmetric), but the direction of the color shift will be wrong in the paired gamut figure. Always verify your phase_labels.csv against known field guides.

Background pixels contaminate the centroid

If your segmented images have residual background pixels (white or magenta), they will pull the centroid toward neutral colors. The extract_fg_rgb() function filters these, but check your images visually if results look unexpectedly low.

How to extend

  • Use pavo::classify() instead of raw pixel sampling for a cluster-center-based approach (more robust to within-image variation).
  • Add a phylomorphospace panel showing IP centroids and TP centroids as paired points in a*–b* space, connected by arrows, with the phylogeny projected underneath.
  • Test dichromatism against mating system (haremic vs. group spawning) using rfishbase::reproduction().
  • Compute a volume-based dichromatism metric using the overlap (or non-overlap) of IP and TP convex hulls in 3D CIELAB space.
