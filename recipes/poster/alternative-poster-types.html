Alternative Poster Types

Four poster designs for four kinds of research questions

The default poster layout works well for the question “Does ecology predict color?” But your group might be asking a very different question. This guide describes four alternative poster designs, each built around a different research theme. Every design uses the same UCLA 48 x 36 in template and the same three-column structure — only the figures, narrative arc, and recipe pathway change.

How to use this page
  1. Read the decision flowchart below to figure out which poster type fits your question.
  2. Jump to that poster type’s section for the recipe pathway, hero figures, and fill-in-the-blank templates.
  3. Run the recipes in order, generate the hero PDFs, and drop them into the poster template.

Decision Flowchart: Which Poster Type Fits Your Question?

Every poster type shares the same foundation

Regardless of which type you choose, every group must run the Foundation Recipe (Color Gamut) and Recipe 1 (Phylogenetic Signal). These establish your clade’s color dataset and confirm whether phylogenetic correction is needed. The poster types below differ in which elective recipes you run and which figures anchor your Results column.

Type 1: Biogeographic Analysis

Tagline: Color across oceans — does geography shape the palette?

Research Question Template

Does color pattern diversity in [your family] differ between [ocean basin A] and [ocean basin B], and can geographic isolation explain the color divergence we observe?

Hypothesis Template

H1: Species from the [Indo-Pacific / Atlantic / Eastern Pacific] will show [higher / lower] chromatic diversity (Jc) and pattern complexity (m) than species from the [other basin], consistent with the prediction that [greater species richness / different light environments / older isolation] promotes [more / less] elaborate color signaling.

H2: After controlling for phylogenetic relatedness, ocean basin will remain a significant predictor of color metrics, indicating that geography shapes color evolution beyond what shared ancestry alone explains.

H3: Geminate species pairs separated by the Isthmus of Panama (if present in our clade) will show [convergent / divergent] color evolution since their ~3 Mya split.

1 Foundation: Color Gamut Build the color dataset

3 Recipe 3: Axis of Diversification Identify the primary color axes (PC1, PC2)
4 Recipe 18: Biogeographic Color Test basin as a predictor of color via phylogenetic ANOVA
5 Recipe 12: Latitude Gradient Test whether color varies with latitude within basins
6 Recipe 23: Continuous ASR Reconstruct ancestral color at the root and key nodes
7 Recipe 25: ggtree Visualization Build the basin-colored phylogeny hero figure

Type 2: Speciation Rates and Color

Tagline: Do colorful lineages diversify faster?

Research Question Template

Do lineages within [your family] that have [higher / more complex / more conspicuous] color patterns also diversify at faster rates, suggesting a link between color evolution and speciation?

Hypothesis Template

H1: Lineages with higher tip-specific diversification rates (estimated by ClaDS) will show [higher / lower] values of [color metric: m, Jc, m_dS, or PC1], consistent with the prediction that [sexual selection on color / ecological divergence in color] promotes speciation.

H2: The relationship between diversification rate and color will remain significant after controlling for body size and trophic level, indicating that color itself — not a correlated ecological trait — is associated with faster diversification.

H3: Disparity-through-time analysis will show a [negative / positive] MDI, consistent with [early-burst / ongoing] color diversification that [matches / contrasts with] the tempo of lineage diversification.

Step Recipe Why
1 Foundation: Color Gamut Build the color dataset
2 Recipe 1: Phylogenetic Signal Confirm phylogenetic signal in color
3 Recipe 3: Axis of Diversification Get PC scores for rate correlation

5 Recipe 26: Rate-Trait Correlation Test whether rates predict color
6 Recipe 19: Disparity Through Time Test whether color diversity accumulated early or late
7 Recipe 24: Node Heights Test Complementary test for rate acceleration/deceleration

Type 3: Discrete Color Pattern Analysis

Tagline: Bars, spots, and stripes — mapping the evolution of pattern elements

Research Question Template

How many times has [pattern element: bars / spots / stripes / eyespots / bicolor pattern] evolved in [your family], and is the presence of this pattern associated with [ecological trait: habitat / defense / sociality]?

Hypothesis Template

H1: [Pattern element] evolved [once / multiple times] in [your family], consistent with [phylogenetic conservatism / convergent evolution driven by shared ecology].

H2: Species with [pattern element] will be associated with [ecological or behavioral trait] (e.g., defended species will be more conspicuous; reef-associated species will have vertical bars; schooling species will have horizontal stripes).

H3: Stripe orientation (pavo aspect ratio A) will differ between [reef-associated] and [pelagic/open-water] species, consistent with the prediction that vertical bars serve disruptive camouflage against complex reef backgrounds while horizontal stripes facilitate schooling coordination.

Type 4: Ecological Drivers of Color

Tagline: Depth, diet, size, and risk — which ecological forces sculpt the reef fish palette?

Research Question Template

Among the ecological variables that vary across species in [your family] — depth, trophic level, body size, growth rate, and vulnerability — which are the strongest predictors of color pattern variation, and do their effects persist after controlling for body size and phylogeny?

Hypothesis Template

H1: Deeper-dwelling species will show [lower chromatic diversity (Jc) / reduced saturation], consistent with the light-environment filter hypothesis.

H2: Herbivorous species (low trophic level) will be [more / less] conspicuous than carnivores, consistent with the prediction that [carotenoid access / territorial signaling / predation risk] shapes the color palette.

H3: Body size will predict pattern complexity (m) via reaction-diffusion scaling, but after size correction, [depth / diet / vulnerability] will remain a significant predictor of the residual color variation.

H4: More vulnerable species will display less conspicuous patterns, consistent with selection for crypsis under high predation risk.

Recipe Pathway (Run in This Order)

Step Recipe Why
1 Foundation: Color Gamut Build the color dataset
2 Recipe 1: Phylogenetic Signal Confirm phylogenetic correction is needed
3 Recipe 3: Axis of Diversification Identify dominant color axes
4 Recipe 7: Body Size and Complexity Test Murray’s allometric scaling rule
5 Recipe 7b: Size-Corrected Residuals Remove the body-size confound
6 Recipe 6: Depth and Color Test light-environment filtering
7 Recipe 8: Diet and Conspicuousness Test trophic level as a predictor
8 Recipe 9: Vulnerability and Crypsis Test predation risk vs. conspicuousness
9 Recipe 25: ggtree Visualization Build the depth-colored phylogeny
Run Recipe 7b before the ecology recipes

Body size correlates with depth, diet, and vulnerability. If you skip size correction, your ecology results may be artifacts of allometry. Run Recipe 7 and 7b first, then test ecology predictors against both the raw color metrics and the size-corrected residuals.

Mixing and Matching

You are not locked into a single poster type. Many strong posters combine elements from two types. Some natural hybrids:

  • Type 2 + Type 4: Run the ClaDS diversification analysis and the ecology suite, then test whether diversification rate correlates with the same ecological variable that predicts color. If depth predicts color AND fast-diversifying lineages are shallow-water specialists, you have a compelling multi-level story.

  • Type 1 + Type 3: Score discrete pattern elements by basin. Did bars evolve independently in both the Atlantic and Indo-Pacific, or is the pattern unique to one ocean? This combines biogeographic framing with discrete character evolution.

  • Type 3 + Type 4: Test whether the presence of discrete pattern elements (bars, spots) is predicted by ecological variables. Recipe 16 already does this for defense, but you could extend it to depth or diet.

Do not run everything

Running all 28 recipes will dilute your poster. Pick one poster type (or a focused hybrid) and do it well. Your poster should tell one clear story supported by 4 figures, not a catalog of every analysis you tried.
